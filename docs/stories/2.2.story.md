
# Story 2.2: Provider-Managed Discounts

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to be able to add a discount percentage to any of my menu items, so that I can run promotions and attract more customers.

---

### Acceptance Criteria:

1.  **Given** a Provider is adding or editing a meal item in the `MealFormModal`,
    **When** they view the form,
    **Then** they must see an optional number input field for "Discount Percentage" (0-100).

2.  **Given** a Provider sets a discount percentage on a meal,
    **When** they save the meal,
    **Then** the `discountPercentage` must be stored with the meal data in the backend.

3.  **Given** a Customer is viewing a meal on the `MealProviderDetails` page that has a discount,
    **When** the `MealCard` is rendered,
    **Then** it must display a visual badge (e.g., "15% OFF"), the original price with a strikethrough, and the new, calculated discounted price.

4.  **Given** a Provider is viewing their own items on the `ManageMenuPage`,
    **When** a meal has a discount,
    **Then** the `ManageableMealCard` must also clearly display the discount information.

5.  **Given** a Customer adds a discounted item to their cart,
    **When** the item is processed by the `CartProvider`,
    **Then** the price stored in the cart for that item must be the final, discounted price.

6.  **Given** a cart contains discounted items,
    **When** the user views the `CartModal` or `CheckoutPage`,
    **Then** all totals must be calculated using the discounted prices of the items.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Meal` interface must be updated to include an optional `discountPercentage?: number;` field.

-   **Backend (`api/mock.ts`):**
    -   Update the default mock data (`MEAL_PROVIDERS_DEFAULT`) to include a `discountPercentage` on a few meal items for testing.
    -   Ensure the meal creation and update logic correctly handles receiving and storing the `discountPercentage`.

-   **Provider UI (`components/MealFormModal.tsx`):**
    -   Add a new `<input type="number">` to the form for the `discountPercentage`. The input should be bound to the component's state.

-   **Cart Logic (`providers/CartProvider.tsx`):**
    -   Modify the `addToCart` function. Before adding a `meal` to the cart state, it must check if `meal.discountPercentage` exists and is greater than zero.
    -   If a discount exists, calculate the final price: `finalPrice = meal.price * (1 - meal.discountPercentage / 100)`.
    -   Create the `CartItem` object using this `finalPrice` in the `price` field. This ensures all downstream calculations are automatically correct.

-   **Customer UI (`components/MealCard.tsx`):**
    -   Add conditional rendering logic. If `meal.discountPercentage` exists, calculate the discounted price for display.
    -   Render the original `meal.price` with a `line-through` style.
    -   Render the calculated discounted price prominently.
    -   Render a badge or tag showing the discount percentage.

-   **Provider UI (`components/ManageableMealCard.tsx`):**
    -   Add similar display logic to the `MealCard` so providers can see their active discounts in their menu management view.
