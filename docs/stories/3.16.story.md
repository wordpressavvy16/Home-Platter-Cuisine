# Story 3.16: Implement Meal "Quick View" Modal

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a Customer browsing a kitchen's menu, I want to click a "Quick View" button on a meal card to see a larger image and full description in a modal, so that I can make a faster purchasing decision without leaving the menu page.

---

### Acceptance Criteria:

1.  **Given** a user is on a `MealProviderDetails` page.
2.  **When** they view a `MealCard`, **Then** a "Quick View" icon/button must be visible.
3.  **Given** the user clicks the "Quick View" button, **Then** a modal must open, overlaying the current page.
4.  **Given** the "Quick View" modal is open, **Then** it must display a large image of the meal, its full description, price, dietary tags, and an "Add to Cart" button.
5.  **Given** the user clicks the "Add to Cart" button within the modal, **Then** the item must be added to their cart, and the modal should remain open.
6.  **Given** the modal is open, **Then** the user must be able to close it by clicking a close button or by clicking the backdrop behind the modal.

---

### Technical Specification:

-   **Component Creation (`components/MealQuickViewModal.tsx`):**
    -   A new, reusable modal component has been created to display detailed meal information.
    -   It uses `ReactDOM.createPortal` to render into the `#modal-root` element.
    -   The modal is styled with the application's glassmorphism theme and is responsive.
    -   It receives a `meal` object and provider details as props and uses the `useCart` hook to handle the "Add to Cart" action.

-   **Component Refactoring (`components/MealCard.tsx`):**
    -   The `MealCard` component now includes a new "Quick View" button (using an `EyeIcon`).
    -   State has been added to the `MealCard` to manage the visibility of the `MealQuickViewModal`.
    -   The main card area is also clickable to open the modal, providing a larger click target.
    -   `e.stopPropagation()` is used on action buttons (`Add`, `Wishlist`, etc.) to prevent them from triggering the modal.

-   **Constants (`constants.tsx`):**
    -   A new `EyeIcon` SVG component has been added for the "Quick View" button.
