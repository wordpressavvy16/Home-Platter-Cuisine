# Story 2.22: Short-Form Video Integration

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to add a link to a short promotional video (like a YouTube Short or Instagram Reel) on my profile, so I can create a more dynamic and engaging storefront. As a Customer, I want to watch this video directly on the provider's page to get a better feel for their food and kitchen.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `EditProfilePage`.
2.  **When** they view the page, **Then** a new input field for "Promotional Video URL" must be available.
3.  **Given** the Provider enters a valid video URL and saves their profile, **Then** the URL must be saved with their provider data.
4.  **Given** a Customer is viewing a `MealProviderDetails` page for a provider who has added a video URL.
5.  **When** the page loads, **Then** a new, prominent section with an embedded video player must be visible.
6.  **Given** the embedded player is visible, **Then** it must correctly parse and display the video from the provided URL (handling YouTube and Instagram formats).
7.  **Given** a provider has not added a video URL, **Then** the video player section must not be visible on their profile page.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Update the `MealProvider` interface to include a new optional string field: `promoVideoUrl?: string;`.

-   **API Layer (`api/mock.ts`):**
    -   The `PUT /api/providers/:id` mock endpoint will be updated to correctly handle saving the new `promoVideoUrl` field when a provider's profile is updated.

-   **Provider UI (`components/EditProfilePage.tsx`):**
    -   A new UI section will be added for the "Promotional Video URL" with a text input.
    -   The main `handleSubmit` function will be updated to include the `promoVideoUrl` in the payload.

-   **Customer UI (`components/MealProviderDetails.tsx`):**
    -   A new "See Our Kitchen in Action!" section will be added.
    -   This section will be conditionally rendered only if `provider.promoVideoUrl` exists.
    -   It will contain a helper function to parse the `promoVideoUrl` and convert it into the correct `embed` URL for an `<iframe>`. This function will need to handle standard YouTube (`/watch?v=`), YouTube Shorts (`/shorts/`), and Instagram Reels (`/reel/`) URL formats.
    -   An `<iframe>` will be used to embed the video player, ensuring a seamless playback experience for the user.

---
