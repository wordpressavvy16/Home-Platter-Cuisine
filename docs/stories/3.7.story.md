# Story 3.7: Professional Application Footer

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a user of the application, I want to see a comprehensive and professional footer at the bottom of the page, so that I can easily find important links like "About Us," "Contact," and social media, which enhances the trustworthiness and usability of the platform.

---

### Acceptance Criteria:

1.  **Given** a user scrolls to the bottom of the `HomePage`.
2.  **When** the page is viewed, **Then** a new, multi-column footer must be visible.
3.  **Given** the footer is displayed, **Then** it must include distinct sections such as "Company," "Contact us," and "Legal".
4.  **Given** the footer is displayed, **Then** it must also include a "Social Links" section with icons for platforms like LinkedIn, Instagram, Facebook, and Twitter.
5.  **Given** the footer is displayed, **Then** it should include placeholder buttons for App Store and Google Play downloads.
6.  **Given** the footer is implemented, **Then** the old, simple footer on the `HomePage` must be replaced by this new, comprehensive component.

---

### Technical Specification:

-   **Component Creation (`components/Footer.tsx`):**
    -   A new, reusable `Footer.tsx` component has been created.
    -   The component uses Tailwind CSS to create a responsive, multi-column layout inspired by modern web applications like Zomato and Swiggy.
    -   It contains hardcoded links for various company, contact, and legal pages.

-   **Constants (`constants.tsx`):**
    -   New SVG icons for LinkedIn, Instagram, Facebook, and Twitter (X) have been added to support the social media links in the footer.

-   **Component Integration (`components/HomePage.tsx`):**
    -   The simple, existing footer has been removed.
    -   The new `<Footer />` component has been imported and rendered at the bottom of the page layout.

---
