
# Story 5.1: AI-Powered Review Summaries for Customers

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Customer viewing a kitchen's details, I want to see an AI-generated summary of all its reviews, so that I can quickly understand its reputation without reading every comment.

---

### Acceptance Criteria:

1.  **Given** a customer is on a `MealProviderDetails` page,
    **Then** a new section titled "AI-Powered Summary" must be visible.

2.  **Given** the provider has fewer than 2 reviews,
    **When** the summary section is viewed,
    **Then** it must state that a summary cannot be generated yet.

3.  **Given** a user is not logged in,
    **When** they view the summary section,
    **Then** it must prompt them to log in to view the AI summary.

4.  **Given** a user is logged in and the provider has 2 or more reviews,
    **When** the `MealProviderDetails` page loads,
    **Then** the review analysis must be triggered automatically.

5.  **Given** the summary is being generated,
    **When** the user views the section,
    **Then** a loading indicator must be clearly displayed.

6.  **Given** the AI analysis is complete,
    **When** the summary is displayed,
    **Then** it must show clear lists of "Strengths" and "Areas for Improvement".

---

### Technical Specification:

-   **Component Creation (`components/AiReviewSummary.tsx`):**
    -   A new, self-contained component `AiReviewSummary` will be created.
    -   It will accept a `reviews: Review[]` array as its primary prop.
    -   It will use the `useAuth` hook to get the user's `token` and `isAuthenticated` status.
    -   It will use internal `useState` hooks to manage its `isLoading`, `error`, and `analysis` result states.

-   **Automatic Analysis Trigger:**
    -   The `AiReviewSummary` component will use a `useEffect` hook that runs on component mount.
    -   The effect will check three conditions before proceeding:
        1.  `isAuthenticated` is `true`.
        2.  `reviews.length` is greater than or equal to a minimum threshold (e.g., 2).
        3.  An analysis is not already `isLoading`.
    -   If conditions are met, it will call the `analyzeReviews` function from `services/geminiService.ts`, passing the reviews and the auth token.

-   **Component Integration (`components/MealProviderDetails.tsx`):**
    -   The new `AiReviewSummary` component will be imported into `MealProviderDetails.tsx`.
    -   It will be placed in a new section between the "Today's Menu" and the "What Customers Are Saying" sections.
    -   It will be instantiated like this: `<AiReviewSummary reviews={provider.reviews} />`.
