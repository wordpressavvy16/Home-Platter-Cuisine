# Story 10.6.2: Revamp Eid Theme with Lanterns (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.1

---

### User Story:
As a user, during Eid, I want to see a theme with beautiful golden lanterns and a rich green/gold color palette, to create a more authentic and immersive festive experience based on traditional imagery.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is activated by the Super Admin.
2.  **When** a user views the application, **Then** the color palette must be updated to a scheme of rich gold and deep green, with a light, elegant background.
3.  **Given** the "Eid" theme is active, **When** a user views the `Header`, **Then** the festive icon must be a new, ornate golden lantern icon, replacing the previous crescent moon.
4.  **Given** the "Eid" theme is active, **When** a user views any page, **Then** a new background animation of gently falling golden lanterns must be visible.
5.  **Given** the new theme is active, **Then** it must present a cohesive, high-quality, and authentic festive appearance.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   A new SVG component, `LanternIcon`, has been created to represent a traditional Fanoos lantern.

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface has been updated to support a new `backgroundEffect` (`lantern-fall`) and `headerIcon` (`lantern`).
    -   The 'Eid' theme object has been completely updated with a new `colors` object reflecting a gold and deep green palette.
    -   The 'Eid' theme's `decorations` have been updated to use `headerIcon: 'lantern'` and `backgroundEffect: 'lantern-fall'`.

-   **Component (`components/Header.tsx`):**
    -   A new `case 'lantern'` has been added to the `FestiveIcon` switch statement, which renders the new `LanternIcon`.

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   A new `if` block has been added to handle the `lantern-fall` background effect.
    -   This logic renders multiple instances of the `LanternIcon` with randomized animations to create the falling effect, using an existing gentle fall animation.
