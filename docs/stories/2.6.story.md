# Story 2.6: Granular Order Status - "Preparing"

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to mark an order as "Preparing" after I've confirmed it, so that the customer is informed that their meal is actively being cooked.

---

### Acceptance Criteria:

1.  **Given** an `Order`'s status is 'CONFIRMED',
    **When** the Provider views the order card in their `OrdersPanel`,
    **Then** a "Mark as Preparing" button must be visible.

2.  **Given** a Provider clicks the "Mark as Preparing" button,
    **When** the action is completed,
    **Then** the order's status must change to 'PREPARING'.

3.  **Given** an `Order`'s status is 'PREPARING',
    **When** the Provider views the order card,
    **Then** the button must change to "Mark as Out for Delivery".

4.  **Given** a Customer is viewing their order history on their `ProfilePage`,
    **When** a provider updates their order's status to 'PREPARING',
    **Then** the customer must see the updated status (e.g., "Preparing your meal").

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Order` interface's `status` field has been updated to include the new state: `status: 'PENDING' | 'CONFIRMED' | 'PREPARING' | 'OUT_FOR_DELIVERY' | 'DELIVERED' | 'CANCELLED';`.

-   **API Layer (`api/orderApi.ts`, `api/mock.ts`):**
    -   The existing `updateOrderStatus` function and the `PUT /api/orders/:orderId/status` mock endpoint handle the 'PREPARING' value.

-   **Provider UI (`components/OrdersPanel.tsx`):**
    -   The conditional logic for rendering action buttons in the `IncomingOrderCard` has been updated:
        -   If `status === 'PENDING'`, show "Accept" and "Cancel".
        -   If `status === 'CONFIRMED'`, show "Mark as Preparing".
        -   If `status === 'PREPARING'`, show "Mark as Out for Delivery".
    -   The `statusStyles` constant has been updated to include a style for the 'PREPARING' state.

-   **Customer UI (`components/ProfilePage.tsx`):**
    -   The `statusStyles` constant has been updated to include a user-friendly text and style for the 'PREPARING' status.
