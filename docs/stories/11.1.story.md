# Story 11.1: Third-Party Delivery Integration (Phase 1 - UI & Simulation)

-   **Epic:** 11 (Logistics & Operations Integration)
-   **Status:** Done

---

### User Story:
As a Provider, I want to be able to enable a third-party delivery service for my kitchen and request a delivery partner for my orders, so I can offload the logistics of delivery and focus on cooking. As a Customer, I want to see the details of my assigned delivery partner when I track my order.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage`.
2.  **When** they view the page, **Then** a new "Delivery Management" panel must be visible.
3.  **Given** the "Delivery Management" panel, **Then** it must contain a toggle switch to "Enable Third-Party Delivery".
4.  **Given** a Provider has enabled third-party delivery and has an order with the status 'PREPARING'.
5.  **When** they view the order in the `OrdersPanel`, **Then** the action button must be "Request Delivery Partner".
6.  **Given** the Provider clicks "Request Delivery Partner", **Then** the button must show a loading state, and a simulated API call must be made.
7.  **Given** the delivery partner is "assigned", **Then** the order's status must automatically change to 'OUT_FOR_DELIVERY', and the assigned partner's details must be saved with the order.
8.  **Given** a Customer is on the `OrderTrackingPage` for an order with an assigned delivery partner, **Then** the partner's name and vehicle details must be clearly displayed.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `MealProvider` interface has been updated to include `deliveryIntegrationEnabled?: boolean;`.
    -   The `Order` interface has been updated to include `deliveryPartner?: { name: string; vehicle: string; phone: string; };`.

-   **API Layer:**
    -   **`api/orderApi.ts`**: A new function `requestDeliveryPartner(orderId, token)` has been created to call `POST /api/orders/:orderId/request-delivery`.
    -   **`api/mock.ts`**: A handler for the new endpoint simulates assigning a delivery partner, updates the order status to 'OUT_FOR_DELIVERY', and adds tracking data.

-   **Component Creation (`components/DeliveryManagementPanel.tsx`):**
    -   A new dashboard panel has been created with a toggle switch to manage the `deliveryIntegrationEnabled` flag for the provider.

-   **Component Refactoring:**
    -   **`DashboardPage.tsx`**: The new `DeliveryManagementPanel` has been added to the layout. The full `providerProfile` is now passed to the `OrdersPanel`.
    -   **`OrdersPanel.tsx`**: The `IncomingOrderCard` now receives the provider's profile. It conditionally renders the "Request Delivery Partner" button if the feature is enabled and the order is 'PREPARING'. It handles the new API call and its loading state.
    -   **`OrderTrackingPage.tsx`**: The component now checks for and displays the `order.deliveryPartner` details if they exist.

-   **Constants (`constants.tsx`):**
    -   The existing `TruckIcon` has been reused for the Delivery Management panel.
