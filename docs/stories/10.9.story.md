# Story 10.6.3: Final Eid Theme Refinement (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.2

---

### User Story:
As a user, during Eid, I want the theme to prominently feature the crescent moon and star symbol, which is central to the festival, while also including decorative golden lanterns to create a complete and authentic festive experience.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the application `Header`, **Then** the primary festive icon must be the `CrescentMoonAndStarIcon`.
3.  **Given** the "Eid" theme is active, **When** a user views any page, **Then** the background animation must be the falling crescent moons and stars.
4.  **Given** the "Eid" theme is active, **When** a user views any page, **Then** two decorative golden lanterns must be visible hanging on the left and right sides of the screen as a secondary decoration.
5.  **Given** the hanging lanterns are visible, **Then** they must have a subtle, gentle swaying animation.
6.  **Given** the theme is active, **Then** it must maintain the rich green and gold color palette.

---

### Technical Specification:

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface has been updated to support a new `sideDecoration` option: `'hanging-lanterns'`.
    -   The 'Eid' theme object has been updated. The `headerIcon` has been set back to `'crescent-moon-star'`, and the `backgroundEffect` has been set back to `'moon-and-stars'`.
    -   A new property, `sideDecoration: 'hanging-lanterns'`, has been added to the Eid theme's `decorations` to incorporate the lanterns without overriding the primary symbols.

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   A new `if` block has been added to the component's rendering logic to handle the `hanging-lanterns` side decoration.
    -   This logic renders two container `div` elements, one positioned on the top-left and one on the top-right.
    -   Each container has a CSS-based chain and renders the `LanternIcon` component, creating the visual of hanging lanterns.
    -   These containers use the existing `gentle-sway` animation.

-   **No Icon Changes:**
    -   This implementation reuses the existing `CrescentMoonAndStarIcon` and `LanternIcon` from `constants.tsx` without modification.
