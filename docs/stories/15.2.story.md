# Story 15.2: Implement Provider Quality Monitoring System

-   **Epic:** 15 (Platform Governance & Trust Tools)
-   **Status:** Done

---

### User Story:
As a Super Admin, I need a system to automatically flag providers who fall below key quality thresholds (like a low average rating or a high order cancellation rate), so that I can proactively investigate potential issues and maintain a high-quality standard across the marketplace.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on their `SuperAdminDashboard`.
2.  **When** the page loads, **Then** a new "Provider Quality Monitoring" panel must be visible.
3.  **Given** a provider's average rating falls below a defined threshold (e.g., 3.5), **Then** they must appear in the quality monitoring list with a reason related to their low rating.
4.  **Given** a provider's order cancellation rate exceeds a defined threshold (e.g., 20%), **Then** they must appear in the quality monitoring list with a reason related to their high cancellation rate.
5.  **Given** no providers meet the at-risk criteria, **Then** the panel must display a message indicating that all provider metrics are currently healthy.

---

### Technical Specification:

-   **Data Model (`api/adminApi.ts`):**
    -   A new interface, `AtRiskProvider`, has been created to structure the data for the API response: `{ provider: MealProvider; reason: string; metric: string; }`.

-   **API Layer:**
    -   **`api/adminApi.ts`**: A new function, `getAtRiskProviders(token)`, has been created to call `GET /api/admin/providers/at-risk`.
    -   **`api/mock.ts`**:
        -   A new handler for `GET /api/admin/providers/at-risk` has been implemented.
        -   This handler iterates through all providers, calculates their order cancellation rate by analyzing the `db.orders` collection, and compares their rating and cancellation rate against hardcoded thresholds.
        -   It returns an array of `AtRiskProvider` objects for any provider failing the checks.

-   **Component Creation (`components/ProviderQualityPanel.tsx`):**
    -   A new panel component has been created for the Super Admin dashboard.
    -   It fetches data using the new `getAtRiskProviders` function.
    -   It displays a list of at-risk providers, showing their name, the reason they were flagged, and their problematic metric.

-   **Component Integration (`components/SuperAdminDashboard.tsx`):**
    -   The new `ProviderQualityPanel` has been added to the dashboard layout.
