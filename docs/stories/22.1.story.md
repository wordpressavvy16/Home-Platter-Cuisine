# Story 22.1: Implement Mobile-First Header and Navigation

-   **Epic:** 22 (Mobile-First Responsive UI/UX Overhaul)
-   **Status:** Done

---

### User Story:
As a user on a mobile device, I want a clean, decluttered header and an intuitive slide-out navigation menu, so that I can easily access all application features without visual clutter or layout issues like overflowing text.

---

### Acceptance Criteria:

1.  **Given** a user is on a small screen (mobile viewport).
2.  **When** they view the application header, **Then** it must only display the logo, theme toggle, cart, and a new "hamburger" menu icon.
3.  **Given** the user is on a large screen (desktop/tablet), **Then** the header must display the full set of navigation links as it currently does.
4.  **Given** the user is on a mobile device and clicks the hamburger menu icon, **Then** a slide-out navigation drawer must open from the side.
5.  **Given** the navigation drawer is open, **Then** it must contain a vertical list of all navigation links (e.g., Dashboard, Profile, Login, Logout), resolving the text overflow issue.
6.  **Given** the navigation drawer is open, **Then** the user can close it by clicking a close button or by tapping the overlay covering the main content.

---

### Technical Specification:

-   **Component (`components/Header.tsx`):**
    -   Introduce a new state variable, `isMobileMenuOpen`, to manage the visibility of the slide-out drawer.
    -   Add a "hamburger" menu icon button (`<Bars3Icon />`) that is only visible on mobile viewports (e.g., using `md:hidden` class). This button will toggle the `isMobileMenuOpen` state.
    -   The existing container for navigation links (`Dashboard`, `Login`, etc.) will be hidden on mobile (e.g., using `hidden md:flex`).
    -   A new, separate UI section for the off-canvas (slide-out) menu will be created.
    -   This section will be conditionally rendered based on `isMobileMenuOpen` and will only be visible on mobile.
    -   It will consist of a semi-transparent overlay and a drawer `div` that slides in from the left.
    -   The drawer will contain all the user navigation links, styled as a vertical list. The existing conditional logic for user roles and authentication status will be duplicated inside this new menu.

---
