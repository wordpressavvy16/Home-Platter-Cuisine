# Story 4.4: Optional Checkout Add-ons

-   **Epic:** 4 (Seamless Ordering & Transaction Flow)
-   **Status:** Done

---

### User Story:
As a Customer, I want to add optional, chargeable extras like cutlery to my order during the checkout process, so that I can have everything I need for my meal delivered conveniently, especially with a small image to show what I'm getting.

---

### Acceptance Criteria:

1.  **Given** a user is on the `CheckoutPage`.
2.  **When** they view the "Order Summary" section, **Then** a new subsection titled "Optional Extras" must be visible.
3.  **Given** the "Optional Extras" section, **Then** it must contain checkboxes for items like "Cutlery Set," each with a clearly displayed image, name, and extra charge.
4.  **Given** a user checks or unchecks an "Optional Extra" box, **Then** the final order total must update instantly and correctly.
5.  **Given** a user successfully places an order with add-ons, **Then** the selected add-ons must be saved as part of the order's data.
6.  **Given** a user views their past orders on the `ProfilePage`, **Then** any selected add-ons for an order must be clearly listed in the order details.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   A new type was created: `export interface OrderAddOn { id: string; name: string; price: number; imageUrl: string; }`.
    -   The `Order` interface was updated to include an optional array: `addOns?: OrderAddOn[];`.

-   **API (`api/orderApi.ts` & `api/mock.ts`):**
    -   A new function `getAvailableAddOns` was created in `orderApi.ts` to fetch add-on options.
    -   A corresponding `/api/addons` endpoint and mock data were added to `mock.ts`.
    -   The `checkout` function signature and its mock handler were updated to accept and save the `addOns`.

-   **Component (`components/CheckoutPage.tsx`):**
    -   Fetches available add-ons using the new API.
    -   Introduced new state to manage selected add-ons.
    -   Renders checkboxes for the available add-ons, including their images.
    -   Updated the `finalTotalPrice` calculation to include the cost of selected add-ons.
    -   The `checkout` API call was modified to include the selected `addOns` in the payload.

-   **Component (`components/ProfilePage.tsx`):**
    -   The `OrderHistoryCard` component was updated to conditionally render a list of `addOns` if they exist on an order.
