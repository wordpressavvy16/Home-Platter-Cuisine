# Story 18.1: Implement Advanced Inventory Management

-   **Epic:** 18 (Core Marketplace Enhancements)
-   **Status:** Done

---

### User Story:
As a Provider, I want to manage a specific stock quantity for each of my menu items (e.g., "15 units available"), so that my inventory is automatically tracked and items are marked as "Sold Out" when the stock runs out. As a Customer, I want to see if an item is low in stock to create a sense of urgency and avoid disappointment.

---

### Acceptance Criteria:

1.  Providers can set a numeric `stockQuantity` for each meal in the `MealFormModal`. A value of `-1` signifies unlimited stock.
2.  The `ManageableMealCard` on the provider's menu page displays the current stock for each item (e.g., "15 in stock", "Unlimited").
3.  When a customer successfully places an order, the `stockQuantity` for the purchased items is automatically decremented in the mock backend.
4.  When an item's `stockQuantity` drops below a certain threshold (e.g., 5), the customer-facing `MealCard` displays a "Low Stock" badge.
5.  When an item's `stockQuantity` reaches 0, it is displayed as "Sold Out," and the "Add to Cart" button is disabled for all users.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Meal` interface has been updated to include `stockQuantity?: number;`.

-   **API Layer (`api/mock.ts`):**
    -   The checkout handler (`POST /api/orders/checkout`) has been updated. After creating an order, it now iterates through the cart items and decrements the `stockQuantity` for the corresponding meal in `db.providers`. It correctly handles a `stockQuantity` of `-1` (unlimited).

-   **Provider UI:**
    -   **`MealFormModal.tsx`**: A new number input for `stockQuantity` has been added. Help text clarifies that `-1` means unlimited.
    -   **`ManageableMealCard.tsx`**: The card now displays the stock status (e.g., "10 in stock", "Unlimited", "Sold Out").

-   **Customer UI (`components/MealCard.tsx`):**
    -   The component's availability logic has been updated to consider `stockQuantity`. An item with `stockQuantity: 0` is now considered unavailable.
    -   It conditionally renders a "Sold Out" badge if `stockQuantity` is `0`.
    -   It conditionally renders a "Low Stock" badge if `stockQuantity` is between 1 and 5.
