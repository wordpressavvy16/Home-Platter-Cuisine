# Story 11.3: Delivery Partner Management & Cost Tracking for Providers

-   **Epic:** 11 (Logistics & Operations Integration)
-   **Status:** Done

---

### User Story:
As a Provider, when my order is being handled by a third-party delivery service, I want to see which partner was assigned and track the associated costs directly on my order dashboard, so I can manage my operations and finances effectively.

---

### Acceptance Criteria:

1.  **Given** an order has been assigned a third-party delivery partner.
2.  **When** the Provider views this order in their `OrdersPanel`, **Then** a new "Delivery Partner" information block must be visible on the order card.
3.  **Given** the delivery partner block is visible, **Then** it must display the partner's name and vehicle details.
4.  **Given** the delivery partner block is visible, **Then** it must also display a clear breakdown of the delivery financials:
    *   The fee paid by the customer (`deliveryFeeApplied`).
    *   The actual cost incurred by the provider (`deliveryCost`).
5.  **Given** an order is handled via self-pickup, **Then** this delivery partner information block must not be visible.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Order` interface has been updated to include an optional field: `deliveryCost?: number;`. This field represents the amount the provider (or platform) pays the delivery partner, which may differ from the fee charged to the customer.

-   **API Layer (`api/mock.ts`):**
    -   The handler for `POST /api/orders/:orderId/request-delivery` has been enhanced.
    -   After assigning a `deliveryPartner`, it now also calculates and adds a simulated `deliveryCost` to the order object. For realism, this cost is set to be slightly less than the `deliveryFeeApplied` (e.g., 85% of the fee).

-   **Component (`components/OrdersPanel.tsx`):**
    -   The `IncomingOrderCard` component has been refactored.
    -   A new section is conditionally rendered if `order.deliveryPartner` exists.
    -   This section displays the `deliveryPartner.name` and `deliveryPartner.vehicle`.
    -   It also includes a financial breakdown, showing the customer-paid `deliveryFeeApplied` (styled as a positive/credit) and the provider's expense `deliveryCost` (styled as a negative/debit).
