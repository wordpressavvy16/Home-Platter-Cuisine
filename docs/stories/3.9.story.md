# Story 3.9: Interactive Map View for Kitchen Discovery

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a Customer, I want to see kitchens plotted on a map, so that I can visually understand their location and proximity to me, providing an alternative and more intuitive way to discover local food options.

---

### Acceptance Criteria:

1.  **Given** a user is on the `HomePage`.
2.  **When** they view the "All Kitchens" section, **Then** a new view-switcher with "List" and "Map" options must be visible.
3.  **Given** the user selects the "Map" view, **Then** the list of provider cards must be replaced with a map-like interface displaying pins for each provider.
4.  **Given** the map is displayed, **Then** it must respect all active search and filter criteria, only showing pins for the providers that match.
5.  **Given** the user clicks on a map pin, **Then** a small info-card must appear, showing the provider's basic details (name, rating, cuisine) and a "View Kitchen" button.
6.  **Given** the user clicks the "View Kitchen" button in the info-card, **Then** they must be navigated to that provider's full `MealProviderDetails` page.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `MealProvider` interface has been updated to include an optional field: `coordinates?: { lat: number; lng: number; };`.

-   **Mock API (`api/mock.ts`):**
    -   The mock database initialization logic has been updated to deterministically generate and add static `coordinates` to each provider. This ensures a consistent map layout on every page load.

-   **Component Creation (`components/MapView.tsx`):**
    -   A new, self-contained component `MapView` has been created to simulate the map interface.
    -   It receives the `filteredProviders` list as a prop.
    -   It renders a stylized `div` as the map background and absolutely positions "pin" icons based on each provider's `coordinates`.
    -   It manages its own internal state to track the currently selected provider pin and display an info-card accordingly.

-   **Component Refactoring (`components/HomePage.tsx`):**
    -   A new `viewMode` state (`'list' | 'map'`) has been added to manage the active view.
    -   A UI control (view-switcher) has been added to allow users to change the `viewMode`.
    -   The component's render logic has been updated to conditionally display either the existing grid of `MealProviderCard`s or the new `MapView` component based on the `viewMode`.

-   **Constants (`constants.tsx`):**
    -   New SVG icons, `MapIcon` and `ListBulletIcon`, have been added for the view-switcher UI.
