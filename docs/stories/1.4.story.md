# Story 1.4: Saved Address Management for Customers

-   **Epic:** 1 (Unified User & Onboarding System)
-   **Status:** Done

---

### User Story:
As a Customer, I want to save multiple delivery addresses to my profile, so that I can quickly select one during checkout without having to re-type it every time.

---

### Acceptance Criteria:

1.  **Given** a Customer is on their `ProfilePage`,
    **When** they view the page,
    **Then** a new section titled "My Addresses" must be visible.

2.  **Given** the "My Addresses" section,
    **When** the user has no saved addresses,
    **Then** a prompt and an "Add New Address" button should be visible.

3.  **Given** a user clicks "Add New Address",
    **When** the action is performed,
    **Then** a modal must appear with a form to enter address details (Name, Street, City, Postal Code, Phone).

4.  **Given** a user is on the `CheckoutPage`,
    **When** they have saved addresses,
    **Then** they must see their saved addresses and be able to select one to auto-fill the shipping form.

5.  **Given** a user is on the `CheckoutPage`,
    **When** they view the address section,
    **Then** they must still have the option to enter a new, different address for that specific order.

---

### Technical Specification:

-   **Component Creation (`components/AddressFormModal.tsx`, `components/AddressManager.tsx`):**
    -   Create `AddressManager.tsx`: A new component for the `ProfilePage` to list addresses and contain the "Add New" button.
    -   Create `AddressFormModal.tsx`: A modal containing the form for adding/editing an address.

-   **API Service (`api/userApi.ts`):**
    -   Create a new function `updateUserAddresses(userId: string, addresses: Address[], token: string): Promise<User>`.
    -   This will make a `PUT` request to `/api/users/:userId/addresses`.

-   **Mock API (`api/mock.ts`):**
    -   Implement a handler for `PUT /api/users/:id/addresses`. This handler will find the specified user in `db.users` and replace their `addresses` array with the new one from the request body.
    -   The `User` object in the mock DB should be updated to include an `addresses: Address[]` field.

-   **Type Definition (`types.ts`):**
    -   Add a new interface for a user's address:
        ```typescript
        export interface Address {
          id: string;
          name: string;
          street: string;
          city: string;
          postalCode: string;
          phone: string;
        }
        ```
    -   Update the `User` interface to include `addresses?: Address[];`.

-   **Component Integration:**
    -   **`ProfilePage.tsx`**: Import and render the new `AddressManager` component.
    -   **`CheckoutPage.tsx`**:
        -   Fetch the user's addresses on component mount.
        -   Display the saved addresses as a list of selectable options (e.g., radio buttons).
        -   When an address is selected, its details should populate the form fields.
        -   Include an option like "Use a different address" that keeps the form fields editable for a one-time address.
