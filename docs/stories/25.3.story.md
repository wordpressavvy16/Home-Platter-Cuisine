# Story 25.3: Implement the Revamped Tiffin Provider Marketplace

-   **Epic:** 25 (UI/UX 2.0 Redesign)
-   **Status:** Approved

---

### User Story:
As a user, after setting my location (or skipping), I want to see a beautifully designed and informative marketplace page that showcases featured kitchens and a filterable list of nearby providers, so I can easily start discovering meals.

---

### Acceptance Criteria:

1.  **Given** a user lands on the `HomePage`, **Then** its layout must be refactored to match the "Tiffin Provider Marketplace" mockup.
2.  **Given** the new `HomePage` is displayed, **Then** it must have a new header section showing the user's location and a profile icon.
3.  **Given** the new `HomePage` is displayed, **Then** a search bar with UI buttons for "Filters," "Pure Veg," "Non-Veg," and "Budget" must be present.
4.  **Given** the new `HomePage` is displayed, **Then** a horizontally scrolling "Featured Tiffins" section must be visible.
5.  **Given** the new `HomePage` is displayed, **Then** a "Tiffins Near You" section must show a vertical list of providers.
6.  **Given** a provider is displayed on the page, **Then** it must use the new `MealProviderCard` design, which includes a large banner, an overlaid circular profile image, rating, cuisine, price range, and an open/closed status.

---

### Technical Specification:

-   **Component (`components/HomePage.tsx`):**
    -   The component will be completely refactored to implement the new marketplace UI.
    -   It will include a new header section that reads the user's location from `localStorage`.
    -   It will implement the new search bar and filter button UI.
    -   It will render a "Featured" provider carousel (e.g., top-rated providers) and a main list for "Tiffins Near You".

-   **Component (`components/MealProviderCard.tsx`):**
    -   The component's UI will be completely redesigned to match the new mockup.
    -   It will use relative and absolute positioning to overlay the circular profile image on the banner image.
    -   It will display the provider's name, rating, cuisine, average cost, and a real-time "Open," "Closed," or "Pre-order" status.
    -   It will no longer display the chef's name or the short description directly on the card.

-   **Utility (`utils/kitchenStatus.ts` - New):**
    -   The `getKitchenAvailability` logic will be extracted from `MealProviderDetails.tsx` into this new shared utility file.
    -   This utility will be used by both `MealProviderDetails.tsx` and the newly refactored `MealProviderCard.tsx` to determine a kitchen's real-time status.

---

### Definition of Done (DoD):
-   [ ] Code implemented as per the technical specification.
-   [ ] The `HomePage` is completely redesigned to match the new marketplace mockup.
-   [ ] The `MealProviderCard` is completely redesigned.
-   [ ] A new `kitchenStatus` utility is created and used.
-   [ ] The application remains responsive and visually polished on all screen sizes.
-   [ ] Story status updated to 'Done' in `changelog.md`.
