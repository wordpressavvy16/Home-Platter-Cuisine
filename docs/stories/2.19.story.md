
# Story 2.19: Refine Catering Feature Discovery

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a user browsing the homepage, I want to discover the catering service through a visually engaging, contextual prompt rather than a simple header link, so that the main navigation remains clean and the catering feature is presented as a high-value, discoverable option.

---

### Acceptance Criteria:

1.  **Given** a user is viewing the main `Header`, **Then** the "Catering" navigation link must be removed.
2.  **Given** a user is on the `HomePage` and has not performed a search or applied any filters, **Then** a new, prominent "Catering Discovery Card" must be visible below the main search bar.
3.  **Given** the Catering Discovery Card is visible, **Then** it must contain an enticing background image, a clear headline (e.g., "Planning an Event?"), a brief description, and a call-to-action button (e.g., "Find a Caterer").
4.  **Given** the user clicks anywhere on the Catering Discovery Card, **Then** they must be navigated to the `/catering` page.
5.  **Given** the user performs a search or applies a filter on the `HomePage`, **Then** the Catering Discovery Card must be hidden to prioritize the filtered results.

---

### Technical Specification:

-   **Component (`components/Header.tsx`):**
    -   The `<nav>` element containing the "Catering" link will be removed from the header component to declutter the main navigation.

-   **Component (`components/HomePage.tsx`):**
    -   A new `<section>` will be added to the component's render block, positioned directly after the search form.
    -   This section will be conditionally rendered, appearing only when `searchTerm` is empty and no manual filters are active.
    -   The section will contain a single `<button>` element styled as a large, visually rich "discovery card."
    -   The card will use a background image, a dark overlay for text contrast, and include a headline, description, and a styled `div` that looks like a button.
    -   The `onClick` handler for the main `<button>` will call `navigate('/catering')`.

---
