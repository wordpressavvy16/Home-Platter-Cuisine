# Story 13.13: Comprehensive UI/UX & System Flaw Resolution (Phase 1)

-   **Epic:** 13 (Pre-Launch Polish & Optimization)
-   **Status:** Done

---

### User Story:
As a Developer, I need to address a set of user-reported UI, UX, and system flaws to improve the application's overall quality, functionality, and user experience.

---

### Acceptance Criteria:

1.  **[UX Flaw - Pre-Order Logic]** The pre-order system must be flexible. If a user misses the lunch window, it must offer same-day dinner if available, not just default to the next day. The "Pre-order" button must become a dropdown selector if multiple future slots are available.
2.  **[System Flaw - AI Summary]** The "AI Review Summary" feature on provider pages must be fixed. The mock API endpoint (`/api/ai/analyze-reviews`) must be correctly implemented to prevent the "endpoint not found" error.
3.  **[Functionality Flaw - Catering]** The "Catering Services" section on the `MealProviderDetails` page must have a functional "Inquire for Catering" button that opens the inquiry modal.
4.  **[UI Flaw - Meal Card]** The `MealCard` UI must be cleaned up. The discount badge and action icons (wishlist/collection) must be repositioned to prevent them from overlapping.

---

### Technical Specification:

-   **Pre-Order Logic (`MealProviderDetails.tsx`, `MealCard.tsx`):**
    -   The `getKitchenAvailability` function has been completely overhauled. It now generates a list of *all available slots* for the next 48 hours.
    -   The `MealCard`'s render logic has been updated. If there's only one available slot, it shows a simple button. If there are multiple slots, it renders a "Pre-order for..." dropdown button that reveals all available time slots.

-   **AI Summary Fix (`api/mock.ts`):**
    -   A new mock handler for `POST /api/ai/analyze-reviews` has been implemented. It now correctly receives the reviews and returns a simulated `AnalysisResult` object, fixing the 404 error.

-   **Catering Button Fix (`MealProviderDetails.tsx`):**
    -   State has been added to manage the `BulkInquiryModal`'s visibility.
    -   A new "Inquire for Catering" button has been added to the Catering section, which sets the state to open the modal.

-   **Meal Card UI Fix (`MealCard.tsx`):**
    -   The card's layout has been redesigned. The discount badge is now positioned in the top-right corner. The wishlist and collection icons have been moved to be inline with the meal title, using a flexbox layout to ensure they never overlap with the badge.
