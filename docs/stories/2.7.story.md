# Story 2.7: Provider Subscription & Billing Panel

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to view my current subscription plan details and billing history on my dashboard, so that I can manage my account and stay informed about my platform costs.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage`,
    **When** they view the page,
    **Then** a new panel titled "My Subscription" must be visible.

2.  **Given** the "My Subscription" panel is displayed,
    **When** the provider data has loaded,
    **Then** it must clearly show their current plan name (e.g., "Growth Plan"), the monthly cost, and the next billing date.

3.  **Given** the "My Subscription" panel,
    **When** a provider views it,
    **Then** a "View Billing History" button must be available.

4.  **Given** the provider clicks the "View Billing History" button,
    **When** the action is performed,
    **Then** a modal must open, displaying a list of their past invoices, with the most recent at the top.

5.  **Given** the invoice list is displayed in the modal,
    **When** a provider views an invoice item,
    **Then** it must show the invoice period, amount, and generated date.

---

### Technical Specification:

-   **Component Creation (`components/SubscriptionPanel.tsx`, `components/InvoiceHistoryModal.tsx`):**
    -   `SubscriptionPanel.tsx`: A component on the `DashboardPage` displays high-level subscription details and contains the button to open the history modal.
    -   `InvoiceHistoryModal.tsx`: A modal component that fetches and displays a list of the provider's past invoices.

-   **API Service (`api/providerApi.ts`):**
    -   A function `getInvoicesForProvider(providerId: string, token: string): Promise<Invoice[]>` makes a `GET` request to `/api/providers/:providerId/invoices`.

-   **Mock API (`api/mock.ts`):**
    -   A handler for `GET /api/providers/:id/invoices` finds all invoices in `db.invoices` that match the given `providerId`.
    -   The `MealProvider` objects in the mock DB have been updated to include a `subscription` field.

-   **Type Definition (`types.ts`):**
    -   A `Subscription` interface has been added for subscription details.
    -   The `MealProvider` interface has been updated to include `subscription: Subscription;`.

-   **Component Integration:**
    -   **`DashboardPage.tsx`**: The `SubscriptionPanel` component is rendered, passing the `provider` object as a prop.
    -   The `SubscriptionPanel` manages the state for the `InvoiceHistoryModal`.
