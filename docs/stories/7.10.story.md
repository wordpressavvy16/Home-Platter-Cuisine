# Story 7.10: Implement Automated Cart Abandonment Workflow

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done
-   **Proposed In:** PRD v3.0

---

### User Story:
As a Provider, I want the platform to automatically detect when a logged-in customer has left items in their cart without purchasing and send them a timely reminder, so that I can recover potentially lost sales and increase my conversion rate without any manual effort.

---

### Acceptance Criteria:

1.  **Given** a logged-in user has items in their cart but closes the application without checking out.
2.  **When** a set amount of time has passed (e.g., 1 hour), **Then** the system should identify this as an "abandoned cart".
3.  **Given** an abandoned cart is detected, **Then** a `Notification` must be automatically sent to that user.
4.  **Given** the user receives the notification, **Then** it must contain a friendly reminder message (e.g., "You have items in your cart! Don't miss out on a delicious homemade meal.").
5.  **Given** a reminder has been sent for a specific cart session, **Then** the system must not send another reminder for that same session to avoid spamming the user.
6.  **Given** the user modifies their cart (adds/removes an item), **Then** the abandonment timer and `reminderSent` flag must be reset.

---

### Technical Specification:

-   **State Management (`providers/CartProvider.tsx`):**
    -   The data structure saved to `localStorage` for the cart will be changed from a simple array to an object: `{ items: CartItem[], lastUpdated: string, reminderSent: boolean }`.
    -   The `useEffect` hook that saves to `localStorage` will update the `lastUpdated` timestamp and reset `reminderSent` to `false` on every change to the cart.
    -   The initial state loader will be updated to correctly parse this new object structure.

-   **Application Logic (`App.tsx`):**
    -   A new `useEffect` hook will be added to run on application load for authenticated users.
    -   This effect will use a `setTimeout` to delay the check slightly (e.g., 10 seconds after load).
    -   The effect will read the cart data from `localStorage`, check if it has items, if `reminderSent` is false, and if `lastUpdated` is more than an hour ago.
    -   If all conditions are met, it will call a new API function to trigger the reminder.

-   **API Layer:**
    -   **`api/userApi.ts`**: A new function `sendCartReminder(token: string)` will be added.
    -   **`api/mock.ts`**: A new handler for `POST /api/users/me/cart-reminder` will be implemented. This handler will find the current user and create a new `Notification` for them, adding it to the `db.notifications` array.
