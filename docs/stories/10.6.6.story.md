# Story 10.6.6: Final Eid Theme Lantern Icon Refinement (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.5

---

### User Story:
As a user, I want the hanging lanterns in the Eid theme to precisely match the ornate, traditional style from the reference images provided, so that the theme achieves a final, high-quality, and authentic aesthetic.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the hanging side decorations, **Then** the lantern icon used must be a new, highly detailed SVG that is a faithful representation of the user-provided reference images.
3.  **Given** the new lantern icon is displayed, **Then** it must use the established golden color scheme to remain consistent with the theme's other elements (`CrescentMoonAndStarIcon`).
4.  **Given** this is the final requested change, **Then** no other part of the application or theme should be altered.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   The SVG markup within the `LanternIcon` component will be replaced with a new, highly-detailed, and ornate design that accurately reflects the shape and style of the reference images.
    -   The new SVG will continue to use the `url(#gold-gradient)` fill to ensure visual consistency.
    -   The `viewBox` will be adjusted to accommodate the new level of detail.
    -   No other components need to be modified as the change is self-contained within the icon's definition.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The `LanternIcon` SVG has been completely redesigned to precisely match the user's reference images.
-   [x] The Eid theme now displays the final, correct lantern icon.
-   [x] The application remains fully functional.
