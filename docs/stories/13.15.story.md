# Story 13.15: Final Footer Button Alignment Fix

-   **Epic:** 13 (Pre-Launch Polish & Optimization)
-   **Status:** Done

---

### User Story:
As a user, I want the app store download buttons in the footer to be perfectly aligned, so the application has a polished and professional appearance on all screen sizes.

---

### Acceptance Criteria:

1.  **Given** a user views the footer of the application.
2.  **When** they inspect the "Download on the App Store" and "Get it on Google Play" buttons.
3.  **Then** the buttons must be perfectly centered relative to each other in their vertical stack, creating a clean, symmetrical appearance.

---

### Technical Specification:

-   **Component (`components/Footer.tsx`):**
    -   The final, definitive fix for this persistent UI bug was to wrap both `<a>` tag buttons inside a parent `<div>`.
    -   This parent `<div>` is given a fixed width (e.g., `w-40`).
    -   The `<a>` tags are made into block-level elements.
    -   The `<img>` tags inside are set to `w-full` and `h-auto` with `object-contain`.
    -   This combination forces both button containers to be the same width, and the images scale proportionally within them, guaranteeing perfect vertical alignment of the buttons themselves.
