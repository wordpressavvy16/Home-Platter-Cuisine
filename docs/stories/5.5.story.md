# Story 5.5: Follow Providers for Updates

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Customer, I want to "follow" my favorite providers, so that I can easily find them again and be notified about their new menu items or announcements in the future.

---

### Acceptance Criteria:

1.  **Given** a Customer views a provider's card or details page, **Then** the "favorite" (heart) icon now represents "following" that provider.
2.  **Given** a Customer clicks the heart icon, **Then** the provider's ID must be added to or removed from their `followedProviderIds` list in their user profile.
3.  **Given** a Customer is on their `ProfilePage`, **Then** the tab previously named "Favorite Kitchens" must be renamed to "Following".
4.  **Given** a Customer views the "Following" tab, **Then** it must display a list of all providers they are currently following.
5.  **Given** this change is implemented, **Then** all underlying data models, API calls, and component logic must be updated from "favorite" to "follow" terminology.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `User` interface has been updated by renaming the `favoriteProviderIds` property to `followedProviderIds`.

-   **API Layer (`api/userApi.ts` & `api/mock.ts`):**
    -   The `updateUserFavorites` function in `userApi.ts` has been renamed to `updateUserFollows`.
    -   The corresponding mock API endpoint in `mock.ts` has been updated from `/api/users/:id/favorites` to `/api/users/:id/follows` and its logic now modifies the `followedProviderIds` property.

-   **UI Components:**
    -   **`HomePage.tsx`, `MealProviderCard.tsx`, `MealProviderDetails.tsx`**: These components have been refactored to use the new `followedProviderIds` property and the `updateUserFollows` function. Prop names and internal variables have been updated to reflect the "follow" terminology (e.g., `isFavorited` becomes `isFollowing`).
    -   **`ProfilePage.tsx`**: The "Favorite Kitchens" tab has been renamed to "Following", and its logic has been updated to render providers from the user's `followedProviderIds` list.
