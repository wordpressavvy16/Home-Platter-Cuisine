# Story 11.2: Customer-Selectable Delivery Options & Cost Calculation

-   **Epic:** 11 (Logistics & Operations Integration)
-   **Status:** Done

---

### User Story:
As a Customer at checkout, I want to choose my preferred delivery method—either self-pickup or third-party delivery—and see the associated costs clearly, so I can make an informed decision and complete my order.

---

### Acceptance Criteria:

1.  **Given** a Customer is on the `CheckoutPage`.
2.  **When** they view the order summary for a provider, **Then** a "Delivery Method" section must be visible.
3.  **Given** the provider has *not* enabled third-party delivery, **Then** the only option shown must be "Self Pickup (Free)".
4.  **Given** the provider *has* enabled third-party delivery, **Then** the user must see two selectable options:
    *   "Self Pickup (Free)"
    *   "Third-Party Delivery (+₹[Fee])"
5.  **Given** the user selects a delivery option, **Then** the final order total must update instantly and accurately to reflect any delivery fee.
6.  **Given** the user places the order, **Then** their chosen `deliveryMethod` and the `deliveryFeeApplied` must be saved with the order data.
7.  **Given** the user views their completed order on the `ProfilePage`, **Then** the selected delivery method and fee must be clearly displayed in the order details.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `MealProvider` interface has been updated to include `deliveryFee?: number;`.
    -   The `Order` interface has been updated to include `deliveryMethod?: 'PICKUP' | 'DELIVERY';` and `deliveryFeeApplied?: number;`.

-   **API Layer:**
    -   **`api/orderApi.ts`**: The `checkout` function signature has been updated to accept a `deliveryMethods: Record<string, 'PICKUP' | 'DELIVERY'>` object.
    -   **`api/mock.ts`**: The checkout handler has been enhanced to process the `deliveryMethods`. It now calculates and adds the `deliveryFee` to the `totalAmount` for each order where delivery is chosen and saves the method and fee to the new order object.

-   **Component (`components/CheckoutPage.tsx`):**
    -   A new state, `deliveryMethods`, has been added to manage the user's selection for each provider in the cart. It defaults to 'PICKUP'.
    -   The order summary section has been updated to render radio buttons for delivery choices, but only for providers who have `deliveryIntegrationEnabled: true`.
    -   The `finalTotalPrice` calculation (`useMemo`) has been updated to include the sum of all selected delivery fees.
    -   The call to `orderApi.checkout` now passes the `deliveryMethods` state.

-   **Component (`components/ProfilePage.tsx`):**
    -   The `OrderHistoryCard` has been updated to conditionally render a new line item displaying the chosen `deliveryMethod` and the `deliveryFeeApplied` if they exist on the order.
