# Story 9.4: Super Admin Master CRM Panel

-   **Epic:** 9 (Platform Administration & Multitenancy)
-   **Status:** Done

---

### User Story:
As a Super Administrator, I want a master CRM panel on my dashboard where I can view and search for all users—both Providers and Customers—so that I can manage the entire user base for support and operational purposes.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminDashboard`,
    **When** the page loads,
    **Then** a new "Master CRM" panel must be visible.

2.  **Given** the Master CRM panel is displayed,
    **When** the data has loaded,
    **Then** it must show a table containing all registered users (Providers and Customers).

3.  **Given** the user table is displayed,
    **When** the admin views a row,
    **Then** it must show the user's Name, Email, Role, and Join Date.

4.  **Given** the Master CRM panel is displayed,
    **When** the admin views it,
    **Then** a search input field must be available to filter users by name or email.

5.  **Given** the admin types "ankit" into the search field,
    **When** the list updates,
    **Then** only users with "ankit" in their name or email should be visible in the table.

---

### Technical Specification:

-   **Component Creation (`components/SuperAdminCrmPanel.tsx`):**
    -   A new, self-contained component `SuperAdminCrmPanel` has been created.
    -   It fetches all users and manages its own state for `isLoading`, `error`, `users`, and `searchTerm`.
    -   It renders a search input and a table of users with client-side filtering.

-   **API Service (`api/adminApi.ts`):**
    -   A new function `getAllUsers(token: string): Promise<User[]>` has been created, which makes a `GET` request to `/api/admin/users`.

-   **Mock API (`api/mock.ts`):**
    -   A handler for `GET /api/admin/users` has been implemented.
    -   This handler augments user data with a `joinDate` before returning the complete list of all users from `db.users`.

-   **Type Definition (`types.ts`):**
    -   The `User` interface has been updated to include an optional `joinDate?: string;`.

-   **Component Integration (`components/SuperAdminDashboard.tsx`):**
    -   The new `SuperAdminCrmPanel` component has been imported and rendered within the dashboard layout.
