# Story 3.10: A Personalized 'For You' Feed

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a logged-in Customer, I want to see a personalized "For You" feed on the homepage that shows me recent updates from the kitchens I follow, so that I can easily keep up with my favorite chefs' latest announcements and specials.

---

### Acceptance Criteria:

1.  **Given** a user is logged out, **When** they visit the `HomePage`, **Then** they must see the standard "Explore" view with curated collections and the "All Kitchens" list.
2.  **Given** a user is logged in, **When** they visit the `HomePage`, **Then** they must see a new tabbed interface with "For You" and "Explore" options, with "For You" selected by default.
3.  **Given** the user is on the "For You" tab, **Then** they must see a chronological feed of items from only the providers they are following.
4.  **Given** the feed is displayed, **Then** it must include different types of updates, such as "New Announcement" and "New Featured Meal", each with a distinct visual presentation.
5.  **Given** the user's feed is empty (they don't follow anyone), **Then** a helpful message should be displayed, encouraging them to explore and follow kitchens.
6.  **Given** the user clicks on the "Explore" tab, **Then** they must be shown the original homepage view with "Top Rated," "New This Week," and "All Kitchens" sections.
7.  **Given** a user performs a search, **Then** they should be automatically switched to the "Explore" tab to see the search results.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   A new `FeedItem` interface has been created to represent a single entry in the user's feed, capable of handling different update types (announcements, featured meals).

-   **API Layer:**
    -   **`api/userApi.ts`**: A new function, `getUserFeed(token)`, has been added to fetch the personalized feed.
    -   **`api/mock.ts`**: A new mock handler for `GET /api/users/me/feed` has been implemented. This logic gathers all announcements and featured meals from the current user's followed providers, combines them into a single array, and sorts them by timestamp in descending order.

-   **Component Creation (`components/FeedCard.tsx`):**
    -   A new, reusable `FeedCard` component has been created to render a single `FeedItem`.
    -   It features a standard header with the provider's information and a body that conditionally renders the content based on the `FeedItem.type`.

-   **Component Refactoring (`components/HomePage.tsx`):**
    -   The component has been significantly refactored to manage the new tabbed view.
    -   A new state, `activeTab`, controls which view is shown.
    -   A `useEffect` hook now fetches the user's feed data when they are authenticated and defaults their view to the "For You" tab.
    -   The main render logic conditionally displays either the new feed (by mapping `feedItems` to `FeedCard` components) or the existing "Explore" content.
