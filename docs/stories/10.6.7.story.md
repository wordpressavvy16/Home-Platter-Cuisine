# Story 10.6.7: Final Lantern Icon Refinement (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.6

---

### User Story:
As a user, I want the Eid theme's hanging lanterns to precisely match the intricate, traditional style from the reference image provided, ensuring the final design is aesthetically pleasing and authentic, not an abstract representation.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the hanging side decorations, **Then** the lantern icon used must be a new, highly detailed SVG that is a faithful representation of the user-provided reference images.
3.  **Given** the new lantern icon is displayed, **Then** it must have a distinct structure with a domed top, a main body section with a yellow glow representing light, and an ornate bottom, as per the reference.
4.  **Given** the new lantern icon is displayed, **Then** it must use the established golden color scheme to remain consistent with the theme's other elements (`CrescentMoonAndStarIcon`).
5.  **Given** this is the final requested change, **Then** no other part of the application or theme should be altered.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   The SVG markup within the `LanternIcon` component will be replaced with a new, highly-detailed, and ornate design that accurately reflects the shape and style of the reference images.
    -   The new design includes a pointed top, a patterned dome, a glowing main body, and a decorative bottom, all styled with the theme's golden gradient to ensure visual consistency.
    -   No other components need to be modified as the change is self-contained within the icon's definition.

---
