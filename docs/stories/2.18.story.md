
# Story 2.18: Enhanced Caterer Profiles & Discovery

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to formally advertise my kitchen's catering services with specific details like the types of events I serve and my guest capacity, so that I can attract larger event-based orders. As a Customer, I want a dedicated page to easily discover and browse providers who offer catering services for my events.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `EditProfilePage`.
2.  **When** they view the page, **Then** a new "Catering Services" section must be available, allowing them to enable catering and input event types and guest capacity (min/max).
3.  **Given** any user is viewing the main `Header`, **Then** a "Catering" navigation link must be visible, leading to the new catering discovery page.
4.  **Given** a user navigates to the `/catering` page, **Then** they must see a list of only those providers who have `cateringEnabled: true`.
5.  **Given** a user is viewing a `MealProviderCard` for a provider who offers catering, **Then** a summary of their guest capacity (e.g., "Cateters for 20 to 100 guests") must be visible on the card.
6.  **Given** a user is on a `MealProviderDetails` page for a provider who offers catering, **Then** a new "Catering Services" section must clearly display their guest capacity and the types of events they service.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Update the `MealProvider` interface to include new optional fields: `cateringEnabled?: boolean;`, `cateringEventTypes?: string[];`, and `cateringGuestCapacity?: { min: number; max: number; };`.

-   **Constants (`constants.tsx`):**
    -   Create and export a `CATERING_EVENT_TYPES` constant, which is an array of objects (`{ id, label }`) defining the standard event types providers can select.

-   **Provider UI (`components/EditProfilePage.tsx`):**
    -   Add a new form section for "Catering Services" with a toggle to enable the feature and inputs for guest capacity and a multi-select checklist for event types based on the new constant.

-   **Core UI (`components/Header.tsx`, `App.tsx`):**
    -   Add a "Catering" link to the `Header`.
    -   Add a new route for `/catering` in `App.tsx` that renders a new `CateringPage` component.

-   **Component Creation (`components/CateringPage.tsx`):**
    -   Create a new page component that fetches all providers and filters the list to show only those where `cateringEnabled` is `true`.
    -   This page will render a grid of `MealProviderCard` components for the filtered results.

-   **Customer UI (`components/MealProviderCard.tsx`, `components/MealProviderDetails.tsx`):**
    -   `MealProviderCard`: Add conditional logic to display the guest capacity if `cateringEnabled` is true.
    -   `MealProviderDetails`: Add a new, visually distinct "Catering Services" section that is conditionally rendered and displays all catering-related information.
