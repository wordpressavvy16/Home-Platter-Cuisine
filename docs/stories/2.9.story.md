# Story 2.9: Granular Order Status - "Out for Delivery"

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, after I have finished preparing an order, I want to mark it as "Out for Delivery" so that the customer knows their food is on its way.

---

### Acceptance Criteria:

1.  **Given** an `Order`'s status is 'PREPARING',
    **When** the Provider views the order card in their `OrdersPanel`,
    **Then** the action button must now read "Mark as Out for Delivery".

2.  **Given** a Provider clicks the "Mark as Out for Delivery" button,
    **When** the action is completed,
    **Then** the order's status must change to 'OUT_FOR_DELIVERY'.

3.  **Given** an `Order`'s status is 'OUT_FOR_DELIVERY',
    **When** the Provider views the order card,
    **Then** the button must change to "Mark as Delivered".

4.  **Given** a Customer is viewing their order history on their `ProfilePage`,
    **When** a provider updates their order's status to 'OUT_FOR_DELIVERY',
    **Then** the customer must see the updated status (e.g., "On its way!").

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Order` interface's `status` field has been updated to include the new state: `status: 'PENDING' | 'CONFIRMED' | 'PREPARING' | 'OUT_FOR_DELIVERY' | 'DELIVERED' | 'CANCELLED';`.

-   **API Layer (`api/mock.ts`):**
    -   The `PUT /api/orders/:id/status` mock endpoint handles the 'OUT_FOR_DELIVERY' status and generates a new notification for the customer.

-   **Provider UI (`components/OrdersPanel.tsx`):**
    -   The conditional logic for rendering action buttons in the `IncomingOrderCard` has been updated for the new flow:
        -   If `status === 'PREPARING'`, the button sets the status to 'OUT_FOR_DELIVERY'.
        -   If `status === 'OUT_FOR_DELIVERY'`, the button sets the status to 'DELIVERED'.
    -   The `statusStyles` constant has been updated to include a style for the 'OUT_FOR_DELIVERY' state.

-   **Customer UI (`components/ProfilePage.tsx`):**
    -   The `statusStyles` constant has been updated to include a user-friendly text and style for the 'OUT_FOR_DELIVERY' status.
