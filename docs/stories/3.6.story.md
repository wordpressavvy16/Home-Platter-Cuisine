# Story 3.6: Advanced Filtering for Kitchens

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a Customer browsing the "All Kitchens" list on the homepage, I want to apply filters for cuisine, rating, and dietary options, so that I can easily narrow down the list of providers to find exactly what I'm looking for.

---

### Acceptance Criteria:

1.  **Given** a user is viewing the "All Kitchens" list on the `HomePage`,
    **When** the page loads,
    **Then** a new "Filters" section must be visible.

2.  **Given** the "Filters" section is visible,
    **When** the user inspects it,
    **Then** it must provide options to filter by:
    *   **Cuisine:** A multi-select checklist, dynamically populated with all unique cuisines from the available providers.
    *   **Minimum Rating:** A set of radio buttons (e.g., "4.5+", "4.0+", "Any").
    *   **Dietary Needs:** A "Veg Only" checkbox.

3.  **Given** a user applies one or more filters (e.g., "North Indian" cuisine and "4.5+" rating),
    **When** the filters are changed,
    **Then** the list of "All Kitchens" must immediately update to show only providers that match all selected criteria.

4.  **Given** one or more filters are active,
    **When** the user views the filter section,
    **Then** a "Clear All" button must be visible and functional, which resets all filters and shows the complete list of kitchens.

---

### Technical Specification:

-   **Component (`components/HomePage.tsx`):**
    -   A new state variable will be introduced to manage the active filters: `const [activeFilters, setActiveFilters] = useState({ cuisines: new Set<string>(), minRating: 0, vegOnly: false });`.
    -   A new UI section for filters will be added above the main kitchen list. This section will be collapsible for a better user experience.
    -   The list of available cuisines will be dynamically generated using a `useMemo` hook that extracts unique cuisines from the `providers` list.
    -   The `filteredProviders` `useMemo` hook will be updated to chain the new filtering logic *after* the existing AI search logic. It will filter by cuisine, rating, and veg-only status based on the `activeFilters` state.
    -   A "Clear All" button will be implemented to reset the `activeFilters` state to its default.

-   **No API or Data Model Changes:** This is a frontend-only enhancement. All necessary data is already available from the existing `getProviders` API call.
