# Story 4.7: Customer Loyalty & Rewards Program

-   **Epic:** 4 (Seamless Ordering & Transaction Flow)
-   **Status:** Done

---

### User Story:
As a Customer, I want to earn loyalty points for every order I place and redeem them for discounts on future orders, so that I feel rewarded for my continued patronage and am incentivized to order again.

---

### Acceptance Criteria:

1.  **Given** a Customer places an order.
2.  **When** the order is marked as 'DELIVERED', **Then** they must earn loyalty points (e.g., 1 point for every ₹10 spent).
3.  **Given** a Customer is on their `ProfilePage`.
4.  **When** they view the page, **Then** a new tab "My Rewards" must be visible, showing their current loyalty points balance and its redemption value (e.g., "100 Points = ₹10 Discount").
5.  **Given** a Customer is on the `CheckoutPage`.
6.  **When** they have a positive loyalty points balance, **Then** an option to "Apply Rewards" must be visible in the order summary.
7.  **Given** the Customer applies their rewards, **Then** the corresponding discount must be applied to their order total, and the points must be deducted from their balance upon successful order placement.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `User` interface has been updated to include an optional field: `loyaltyPoints?: number;`.
    -   The `Order` interface has been updated to include optional fields: `pointsEarned?: number;` and `pointsRedeemed?: number;`.

-   **API Layer (`api/mock.ts`):**
    -   The `updateOrderStatus` handler has been modified. When an order's status is set to `'DELIVERED'`, it now calculates points earned (e.g., `Math.floor(order.totalAmount / 10)`), adds them to the customer's `loyaltyPoints` balance, and records the amount on the order.
    -   The `checkout` handler has been modified. It now accepts an optional `redeemPoints` boolean. If true, it calculates the discount, deducts the points from the user's balance, updates the order's `totalAmount`, and records the points redeemed.

-   **API Service (`api/orderApi.ts`):**
    -   The `checkout` function signature has been updated to accept an optional `redeemPoints` boolean.

-   **UI Components:**
    -   **`ProfilePage.tsx`**:
        -   A new "My Rewards" tab has been added.
        -   This tab displays the user's current `loyaltyPoints` balance and calculates its monetary value.
        -   The `OrderHistoryCard` has been updated to show points earned or redeemed for each order.
    -   **`CheckoutPage.tsx`**:
        -   A new state, `redeemPoints`, has been added.
        -   A UI checkbox has been added to allow users to apply their rewards.
        -   The `finalTotalPrice` calculation has been updated to subtract the loyalty discount.
        -   The `redeemPoints` state is passed to the `orderApi.checkout` call.

-   **Constants (`constants.tsx`):**
    -   A new `GiftIcon` has been added for the rewards UI.
