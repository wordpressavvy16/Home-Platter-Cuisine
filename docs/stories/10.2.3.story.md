# Story 10.2.3: Enhance Christmas Theme with Animated Header Icon (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.2.2

---

### User Story:
As a user, when the Christmas theme is active, I want to see a playful, animated Santa icon in the header instead of a static one, to make the festive theme more dynamic and delightful.

---

### Acceptance Criteria:

1.  **Given** the "Christmas" festive theme is activated.
2.  **When** a user views the application `Header`, **Then** the static Santa hat and bells icon must be replaced with a new, animated Santa Claus icon.
3.  **Given** the animated Santa icon is displayed, **Then** it must feature a minimalistic Santa figure with a gentle walking motion.
4.  **Given** the animation is active, **Then** it should also include a subtle, repeating animation of gifts falling from Santa's sack.
5.  **Given** the animation is active, **Then** it must be clean, elegant, and not distracting to the user's primary navigation.

---

### Technical Specification:

-   **Animation (`index.html`):**
    -   New CSS keyframe animations, `santa-walk` and `gift-fall`, have been added to create the desired motion effects for the SVG icon.
    -   These animations are registered in the Tailwind config's `animation` theme.

-   **Component (`constants.tsx`):**
    -   A new SVG component, `AnimatedSantaIcon`, has been created.
    -   This component contains the SVG markup for a minimalistic Santa Claus, with separate elements for the body and falling gifts.
    -   The `santa-walk` and `gift-fall` animation classes are applied to the respective SVG elements to bring the icon to life.
    -   The old static `ChristmasIcon` component has been removed as it is now obsolete.

-   **Component (`components/Header.tsx`):**
    -   The `FestiveIcon` component's switch statement has been updated. The `case 'christmas'` has been replaced with `case 'animated-santa'`, which now renders the new `AnimatedSantaIcon` component.

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface has been updated to include `'animated-santa'` as a valid `headerIcon` option.
    -   The 'Christmas' theme object's `decorations.headerIcon` property has been changed from `'christmas'` to `'animated-santa'`.
