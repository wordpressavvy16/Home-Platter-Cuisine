# Story 9.1: Super Admin KPI Dashboard Panel

-   **Epic:** 9 (Platform Administration & Multitenancy)
-   **Status:** Done

---

### User Story:
As a Super Administrator, when I view my dashboard, I want to see a panel with key platform metrics like total revenue, total orders, and user counts, so that I can quickly assess the overall health and growth of the business.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminDashboard`,
    **When** the page loads,
    **Then** a new KPI panel must be visible above the other panels.

2.  **Given** the KPI panel is displayed,
    **When** the data has loaded,
    **Then** it must contain distinct cards showing:
    -   Total Platform Revenue (sum of all completed orders)
    -   Total Orders Placed
    -   Total Active Providers
    -   Total Registered Customers

3.  **Given** the KPI cards are displayed,
    **When** the admin views them,
    **Then** each card must have a clear title, the calculated value, and a relevant icon.

---

### Technical Specification:

-   **Component Creation (`components/SuperAdminKpiPanel.tsx`):**
    -   A new, self-contained component `SuperAdminKpiPanel` has been created.
    -   It fetches the KPI data and renders individual KPI cards.
    -   It manages its own `isLoading` and `error` states.

-   **API Service (`api/adminApi.ts`):**
    -   A new function `getPlatformKpis(token: string): Promise<PlatformKpis>` makes a `GET` request to `/api/admin/kpis`.

-   **Mock API (`api/mock.ts`):**
    -   A handler for `GET /api/admin/kpis` has been implemented.
    -   It performs calculations on the mock database for `totalRevenue`, `totalOrders`, `totalProviders`, and `totalCustomers`.

-   **Type Definition (`types.ts`):**
    -   A new `PlatformKpis` interface has been added for the API response.

-   **Component Integration (`components/SuperAdminDashboard.tsx`):**
    -   The new `SuperAdminKpiPanel` component is imported and rendered at the top of the main content area.
