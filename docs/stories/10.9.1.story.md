# Story 10.6.4: Eid Theme Visual Polish (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.3

---

### User Story:
As a user, when the Eid theme is active, I want the crescent moon and star icon to have a stylized, golden appearance that matches the aesthetic of the hanging lanterns, ensuring a visually cohesive and high-quality festive theme.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the application `Header`, **Then** the `CrescentMoonAndStarIcon` must render with a golden color/gradient that matches the hanging lanterns, not a plain color.
3.  **Given** the "Eid" theme is active, **When** a user views the background animation, **Then** the falling particles must also be the same stylized, golden crescent moon and star icon.
4.  **Given** the icon is updated, **Then** its shape must be refined to a more stylized, visually appealing design as per the user's reference image.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   The SVG markup within the `CrescentMoonAndStarIcon` component has been completely replaced.
    -   The new SVG uses a `<defs>` section with a `<linearGradient>` to create a rich, golden effect.
    -   The `<path>` elements for the moon and star now use this gradient for their `fill`, making the icon's color intrinsic to its definition. This removes the need for external CSS `text-color` classes to color it.

-   **Component (`components/Header.tsx`):**
    -   The `className` for the `crescent-moon-star` case in the `FestiveIcon` switch statement has been updated. The previous color class (`text-gray-300`) has been removed to allow the new SVG's intrinsic gradient to display correctly. A slightly larger size and more pronounced drop shadow have been applied for better visibility.

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   In the logic for the `moon-and-stars` background effect, the `className` on the `CrescentMoonAndStarIcon` has been updated. The `text-white` class has been removed, and a `drop-shadow-lg` has been added to ensure the golden icons stand out against the background.
