# Story 7.3: AI-Assisted Broadcast Messaging

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, when composing a new broadcast announcement, I want to use an "AI Assist" button to help me refine my draft into more compelling and professional marketing copy, so that I can save time and improve customer engagement.

---

### Acceptance Criteria:

1.  **Given** a Provider has opened the "Create Broadcast" modal (`BroadcastModal.tsx`),
    **When** they view the modal,
    **Then** the "AI Assist" button must now be enabled and clickable.

2.  **Given** a Provider has typed a draft message into the textarea (e.g., "new biryani this weekend 10% off"),
    **When** they click the "AI Assist" button,
    **Then** a loading state must appear on the button.

3.  **Given** the AI has processed the draft,
    **When** the response is received,
    **Then** the text in the textarea must be replaced with the AI-refined message (e.g., "📣 Exciting News! We're launching a delicious new Biryani this weekend. To celebrate, enjoy a special 10% discount on your order! 🎉").

4.  **Given** the AI refinement is complete,
    **When** the user views the button,
    **Then** the loading state must disappear, and the button should be ready for another use.

---

### Technical Specification:

-   **AI Service (`services/geminiService.ts`):**
    -   A new function has been created: `refineBroadcastMessage(draftMessage: string, token: string): Promise<{ refinedMessage: string }>`.
    -   This function makes a `POST` request to a secure backend endpoint: `/api/ai/refine-broadcast`.

-   **Mock API (`api/mock.ts`):**
    -   A mock handler for `POST /api/ai/refine-broadcast` has been implemented to return a simple, hardcoded transformation for testing.

-   **Provider UI (`components/BroadcastModal.tsx`):**
    -   The "AI Assist" button is now fully functional.
    -   A state variable, `isRefining`, manages the loading state.
    -   The `onClick` handler for the button calls the `refineBroadcastMessage` service function and updates the `message` state with the returned text.
