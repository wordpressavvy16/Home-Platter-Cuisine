# Story 6.3: AI-Powered Menu Analysis & Optimization

-   **Epic:** 6 (AI-Powered Business Intelligence Suite for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, I want an AI-powered tool that acts like a business consultant, analyzing my entire menu to give me actionable advice on pricing, descriptions, and variety, so I can optimize my offerings to increase sales and customer satisfaction.

---

### Acceptance Criteria:

1.  **Given** a Provider is on the `AnalyticsPage`.
2.  **When** they view the page, **Then** a new panel titled "AI Menu Optimization" must be visible.
3.  **Given** the provider has no menu items, **When** they view the panel, **Then** the "Analyze" button must be disabled with a message indicating they need to add meals first.
4.  **Given** a provider clicks the "Analyze My Menu" button, **Then** a loading state must be shown while the AI performs its analysis.
5.  **Given** the analysis is complete, **Then** the results must be displayed in distinct sections:
    *   **Strengths:** What the menu does well (e.g., "Good variety of vegetarian options").
    *   **Opportunities:** Suggestions for new items or categories (e.g., "Consider adding more appetizers").
    *   **Pricing Analysis:** A brief on the overall pricing strategy (e.g., "Prices are competitive...").
    *   **Description Analysis:** Advice on improving meal descriptions (e.g., "Descriptions could be more evocative...").
6.  **Given** the results are displayed, **Then** a button to "Analyze Again" must be available.

---

### Technical Specification:

-   **Component Creation (`components/MenuAnalysisPanel.tsx`):**
    -   A new, self-contained component `MenuAnalysisPanel` has been created. It accepts `menu: Meal[]` as a prop.
    -   It manages its own internal state for `isLoading`, `error`, and the `analysis` result.
    -   It contains the UI to trigger the analysis and display the structured results.

-   **AI Service (`services/geminiService.ts`):**
    -   A new function `analyzeMenu(menu: Meal[], token: string): Promise<MenuAnalysis>` has been created.
    -   This function calls a new backend endpoint: `POST /api/ai/menu-analysis`.

-   **Mock API (`api/mock.ts`):**
    -   A mock handler for `POST /api/ai/menu-analysis` has been implemented.
    -   It receives the menu and returns a plausible, hardcoded `MenuAnalysis` object, simulating a real AI response.

-   **Type Definition (`types.ts`):**
    -   A new interface, `MenuAnalysis`, has been added to define the structure of the AI's response.

-   **Component Integration (`components/AnalyticsPage.tsx`):**
    -   The new `MenuAnalysisPanel` component is imported and rendered.
    -   The provider's full `menu` is passed to it as a prop.
