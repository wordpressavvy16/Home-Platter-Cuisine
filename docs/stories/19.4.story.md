
# Story 19.4: Super Admin Contextual Governance Actions

-   **Epic:** 19 (The Unified CRM Hub)
-   **Status:** Done

---

### User Story:
As a Super Admin, while viewing a user's master profile, I want to see all their associated support tickets and order disputes, and be able to take direct administrative action (e.g., "Issue Compensation Coupon," "Reply to Ticket"), so I can resolve issues efficiently without cross-referencing multiple panels.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminUserProfilePage`.
2.  **When** they view the "Order History" tab, **Then** any order with an open dispute must be visually highlighted and display a "Resolve & Compensate" button.
3.  **Given** the admin clicks "Resolve & Compensate" on a disputed order, **Then** the `CompensationModal` must open, pre-filled with the context of that order and customer.
4.  **Given** the admin successfully sends compensation, **Then** the dispute must be resolved, and the page data must refresh to reflect the change.
5.  **Given** the admin views the "Support Tickets" tab, **Then** a "View & Reply" button must be visible for each ticket.
6.  **Given** the admin clicks "View & Reply" on a ticket, **Then** the `TicketConversationModal` must open, allowing them to view the full thread and send a reply.

---

### Technical Specification:

-   **Component (`components/SuperAdminUserProfilePage.tsx`):**
    -   The component will be enhanced to manage the state for the `CompensationModal` and the `TicketConversationModal`.
    -   **Order History Tab:** The logic for rendering orders will be updated to check if `order.dispute && order.dispute.status === 'OPEN'`. If true, it will render a visual indicator (e.g., an icon) and the "Resolve & Compensate" button. The button's `onClick` handler will open the `CompensationModal`.
    -   **Support Tickets Tab:** The logic for rendering tickets will be updated to include a "View & Reply" button for each ticket. The button's `onClick` handler will open the `TicketConversationModal`.
    -   Callbacks (`onCompensationSent`, `onUpdate`) will be passed to the modals to trigger a re-fetch of all page data upon successful action, ensuring the UI is up-to-date.

-   **No New Components or API Changes:** This story leverages existing modals (`CompensationModal`, `TicketConversationModal`) and API functions (`adminApi.resolveDispute`, `adminApi.issueCompensationCoupon`, `supportApi.addMessageToTicket`) to add contextual actions to the new user profile view.
