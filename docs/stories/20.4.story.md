# Story 20.4: Customer Plan Management & Pause/Resume UI

-   **Epic:** 20 (Tiffin Service Subscription Engine)
-   **Status:** Done

---

### User Story:
As a Customer, I want a section in my profile to view my active tiffin plans and a feature to pause and resume my subscription for a specific date range.

---

### Acceptance Criteria:

1.  A new "My Tiffin Plans" tab is available in the user's `ProfilePage`.
2.  This tab displays a list of the user's active and paused subscription plans.
3.  Each subscription card shows the provider name, plan name, current status ('ACTIVE' or 'PAUSED'), and the current end date.
4.  For 'ACTIVE' subscriptions, a "Pause Plan" button is visible.
5.  Clicking "Pause Plan" opens a `PausePlanModal` where the user can select a "Pause From" date and a "Resume On" date.
6.  The form includes validation to ensure the end date is after the start date.
7.  Submitting the form calls a new API endpoint to update the subscription's status to 'PAUSED' and extend its `endDate` by the duration of the pause.
8.  After a successful pause, the UI on the profile page updates to show the 'PAUSED' status and the new, extended end date.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `SubscriptionOrder` interface has been updated to include an optional `pausePeriods?: { startDate: string; endDate: string }[]` to track pause history.

-   **API Layer (`api/orderApi.ts` & `api/mock.ts`):**
    -   A new function `getSubscriptionOrdersForUser(userId, token)` has been created to call `GET /api/subscriptions/user/:userId`.
    -   A new function `pauseSubscription(subscriptionId, pauseStartDate, pauseEndDate, token)` has been created to call `PUT /api/subscriptions/:subscriptionId/pause`.
    -   Mock handlers for these new endpoints have been implemented. The pause handler calculates the pause duration in days, extends the `endDate` of the subscription, updates its status to `PAUSED`, and adds the pause period to the `pausePeriods` array.

-   **Component Creation:**
    -   `components/SubscriptionManagementPanel.tsx`: A new panel that fetches and displays the user's subscriptions.
    -   `components/PausePlanModal.tsx`: A new modal containing the form for pausing a plan.

-   **Component Integration (`components/ProfilePage.tsx`):**
    -   A new "My Tiffin Plans" tab has been added to the navigation.
    -   The `SubscriptionManagementPanel` is rendered when this tab is active.
    -   A new `CalendarDaysIcon` has been added to `constants.tsx` for the tab icon.
