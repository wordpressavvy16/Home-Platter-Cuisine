# Story 13.12: Homepage Card Symmetry & Layout Consistency

-   **Epic:** 13 (Pre-Launch Polish & Optimization)
-   **Status:** Done

---

### User Story:
As a user browsing the homepage, I want all the cards in a single horizontal row (like in the "Top Rated" or "Community Collections" sections) to have the same height, regardless of their content, so that the layout looks clean, professional, and visually appealing.

---

### Acceptance Criteria:

1.  **Given** a user is on the `HomePage`.
2.  **When** they view any horizontal collection of cards (`MealProviderCard` or `CollectionCard`).
3.  **Then** all cards within that same row must be of equal height, aligning perfectly at the top and bottom.
4.  **Given** a `MealProviderCard` is displayed, **Then** its internal layout must be consistent, reserving space for the optional "Caters for..." text even if it's not present, to prevent misalignment.

---

### Technical Specification:

-   **Component (`components/MealProviderCard.tsx`):**
    -   The root `div` has been updated to use flexbox (`flex flex-col`). This allows child elements to grow and shrink.
    -   The main content area (`p-4`) has been given `flex-grow` to ensure it expands to fill available space.
    -   The container for the optional "Caters for..." text has been given a `min-h-[2.5rem]` to reserve a consistent amount of vertical space, ensuring perfect alignment across all cards.
    -   The card's root element now includes the `h-full` class to make it stretch to the height of its parent grid cell.

-   **Component (`components/CollectionCard.tsx`):**
    -   The root `div` of the `CollectionCard` component has been updated to include the `h-full` class. This makes it stretch to match the height of the tallest card in its row, using the browser's native grid/flexbox behavior.
