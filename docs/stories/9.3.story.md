# Story 9.3: AI-Powered Provider Invoicing

-   **Epic:** 9 (Platform Administration & Multitenancy)
-   **Status:** Done

---

### User Story:
As a Super Administrator, I want to generate and view monthly invoices for each provider based on their activity, so that I can manage the platform's billing and monetization cycle.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminDashboard`,
    **When** the page loads,
    **Then** a new "Provider Invoicing" panel must be visible.

2.  **Given** the Invoicing panel is displayed,
    **When** the admin views it,
    **Then** it should show a list of providers and a button to "Generate Invoice" for the previous month.

3.  **Given** the admin clicks "Generate Invoice" for a provider,
    **When** the action is performed,
    **Then** a loading state should appear, and an invoice should be created and displayed in a list.

4.  **Given** an invoice is displayed,
    **When** the admin views it,
    **Then** it must contain details like the provider's name, invoice period, a base subscription fee, and an AI-generated summary of the month's activity (e.g., "A successful month with high sales in the 'Thali' category.").

5.  **Given** an invoice has been generated,
    **When** the admin views the provider's row,
    **Then** the button should change to "View Invoice".

---

### Technical Specification:

-   **Component Creation (`components/ProviderInvoicingPanel.tsx`):**
    -   A new, self-contained component `ProviderInvoicingPanel` has been created.
    -   It fetches all providers and the list of existing invoices.
    -   It displays a list of providers with a button to generate an invoice.

-   **API Service (`api/adminApi.ts`):**
    -   New functions have been created:
        -   `getInvoices(token: string): Promise<Invoice[]>` -> `GET /api/admin/invoices`
        -   `generateInvoice(providerId: string, token: string): Promise<Invoice>` -> `POST /api/admin/invoices`

-   **Mock API (`api/mock.ts`):**
    -   A new `db.invoices` array has been added to the mock database.
    -   A handler for `POST /api/admin/invoices` has been implemented to create a new `Invoice` object with simulated AI notes and add it to `db.invoices`.
    -   A handler for `GET /api/admin/invoices` returns the `db.invoices` list.

-   **Type Definition (`types.ts`):**
    -   A new `Invoice` interface has been added to support the feature.

-   **Component Integration (`components/SuperAdminDashboard.tsx`):**
    -   The new `ProviderInvoicingPanel` component has been imported and rendered within the dashboard layout.
