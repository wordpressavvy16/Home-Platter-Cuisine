
# Story 19.3: Super Admin Master 360-Degree View

-   **Epic:** 19 (The Unified CRM Hub)
-   **Status:** Done

---

### User Story:
As a Super Admin, when I click on any user in the Master CRM, I want to see a powerful 360-degree view that shows their complete platform history, including all orders placed with any provider, all reviews they've submitted, and their full support ticket history, so I have a holistic view for support and governance.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminCrmPanel`.
2.  **When** they click on a user's row in the table, **Then** they must be navigated to a new page, `SuperAdminUserProfilePage`, for that specific user.
3.  **Given** the `SuperAdminUserProfilePage` loads, **Then** it must display key stats for that user, including their total orders, total spend across the platform, and total support tickets submitted.
4.  **Given** the page is displayed, **Then** it must contain a tabbed interface with "Order History," "Reviews Submitted," and "Support Tickets".
5.  **Given** the "Order History" tab is selected, **Then** it must show a list of *all* orders placed by this user, regardless of the provider.
6.  **Given** the "Reviews Submitted" tab is selected, **Then** it must show all reviews written by this user.
7.  **Given** the "Support Tickets" tab is selected, **Then** it must show all support tickets created by this user.

---

### Technical Specification:

-   **Component Creation (`components/SuperAdminUserProfilePage.tsx`):**
    -   A new page component will be created to render the master 360-degree view.
    -   It will extract the `userId` from the URL.
    -   It will use multiple API calls to fetch all necessary data: `userApi.getUserProfile`, `orderApi.getOrdersForUser`, `adminApi.getAllProviders` (to filter reviews), and `supportApi.getAllTickets` (to filter tickets).
    -   The UI will be structured with key stat cards and a tabbed interface to display the consolidated data.

-   **Routing (`App.tsx`):**
    -   A new route, `/super-admin/user/:userId`, will be added to the main application router to render the `SuperAdminUserProfilePage`.

-   **Component Refactoring (`components/SuperAdminCrmPanel.tsx`):**
    -   The component will be updated to accept the `navigate` function as a prop.
    -   The `<tr>` elements in the user table will be given an `onClick` handler that navigates to the new detail page: `navigate('/super-admin/user/' + user.id)`.
