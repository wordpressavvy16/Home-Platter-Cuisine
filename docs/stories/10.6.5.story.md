# Story 10.6.5: Refine Eid Theme Lantern Icon (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6.4

---

### User Story:
As a user, when the Eid theme is active, I want the hanging lanterns to be more detailed and ornate to match the high-quality aesthetic of the new moon and star icon, creating a truly beautiful and authentic festive theme.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the hanging lanterns on the sides of the screen, **Then** the icon used must be a new, more detailed and traditional design, replacing the previous simple icon.
3.  **Given** the new lantern icon is displayed, **Then** it must use a golden color scheme that is consistent with the `CrescentMoonAndStarIcon`.
4.  **Given** the icon is updated, **Then** the overall theme must feel more polished, cohesive, and visually appealing.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   The SVG markup within the `LanternIcon` component has been completely replaced with a new, more ornate design that resembles a traditional Fanoos (Islamic lantern).
    -   The new SVG's `fill` attribute has been set to `url(#gold-gradient)`, the same gradient used by the `CrescentMoonAndStarIcon`, to ensure perfect visual consistency between the theme's decorative elements.
    -   No other components need to be modified, as the `BackgroundDecorator.tsx` already references the `LanternIcon` component. Updating the icon's definition in this central location ensures the change is applied wherever it is used.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The `LanternIcon` SVG has been completely redesigned to be ornate and golden.
-   [x] The Eid theme now correctly displays this new, higher-quality lantern icon as its side decoration.
-   [x] The application remains fully functional with a more polished and authentic theme.
-   [x] Story status updated to 'Done' in `changelog.md`.
