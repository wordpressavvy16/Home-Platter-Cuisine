# Story 20.5: Automated Pause/Resume Notifications & Provider Dashboard Integration

-   **Epic:** 20 (Tiffin Service Subscription Engine)
-   **Status:** Done

---

### User Story:
As a Provider, I need to be automatically notified when a customer pauses or resumes their plan, and I want to see the current status of all my subscribers on my dashboard.

---

### Acceptance Criteria:

1.  A new draggable panel titled "Subscribers" is available on the `DashboardPage`.
2.  The panel displays a list of all the provider's active and paused tiffin plan subscribers.
3.  Each subscriber in the list shows their name, plan, status ('ACTIVE' or 'PAUSED'), and relevant dates (end date for active, resume date for paused).
4.  When a customer pauses their subscription, a notification is automatically generated for the provider (e.g., "[Customer Name]'s plan is paused...").
5.  On the morning a customer's plan is scheduled to resume, a reminder notification is generated for the provider (e.g., "Reminder: [Customer Name]'s plan resumes today.").
6.  The subscriber list on the dashboard provides a clear, at-a-glance view of the provider's recurring customer base and their current status.

---

### Technical Specification:

-   **API Layer:**
    -   **`api/orderApi.ts`**: A new function `getSubscriptionOrdersForProvider(providerId, token)` has been created to call `GET /api/subscriptions/provider/:providerId`.
    -   **`api/mock.ts`**:
        -   A new handler for the `GET` endpoint has been implemented to filter and return subscriptions for a specific provider.
        -   The handler for `PUT /api/subscriptions/:id/pause` has been enhanced to generate two `Notification` objects for the provider: one immediately for the pause, and a second one "scheduled" for the resume date.

-   **Component Creation (`components/SubscriberPanel.tsx`):**
    -   A new dashboard panel component has been created.
    -   It fetches subscription data using the new `getSubscriptionOrdersForProvider` API.
    -   It renders a list of subscribers, displaying their name, plan details, status, and relevant dates.

-   **Component Integration (`components/DashboardPage.tsx`):**
    -   `'subscribers'` has been added to the `DEFAULT_LAYOUT` array.
    -   The `dashboardPanels` object has been updated to render the new `SubscriberPanel` component, passing the `providerId`.
