# Story 2.21: Provider Catering Quote & Customer Booking Confirmation

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, after receiving a catering inquiry, I want to send a formal, in-app quote to the customer. As a Customer, I want to receive this quote and be able to accept and pay for it directly, so that we can finalize the booking in a secure and professional manner.

---

### Acceptance Criteria:

1.  **Given** a Provider is viewing a catering inquiry in their `ConversationModal`.
2.  **When** they view the modal, **Then** a "Send Formal Quote" button must be visible.
3.  **Given** the Provider clicks this button, **Then** a new modal (`QuoteFormModal`) must open, allowing them to enter a total price and an optional expiration date.
4.  **Given** the Provider submits the quote, **Then** a new, special "quote" message must be sent to the conversation thread, clearly displaying the quoted amount.
5.  **Given** the Customer views this quote message, **Then** an "Accept & Pay" button must be visible to them. This button must be hidden from the provider's view.
6.  **Given** the Customer clicks "Accept & Pay", **Then** they must be navigated to the `CheckoutPage` in a special "catering checkout" mode, pre-filled with the inquiry details and the quoted amount.
7.  **Given** the Customer successfully completes the payment, **Then** a new `Order` must be created, linked to the original inquiry, and the quote message in the conversation must be updated to an "Accepted" state.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Message` interface will be updated with `messageType?: 'text' | 'quote'` and an optional `quote` object.
    -   The `Order` interface will be updated with an optional `cateringInquiryId?: string;`.

-   **API Layer:**
    -   **`api/inquiryApi.ts`**: A new function `sendQuote(inquiryId, quoteData, token)` will be added. A `getInquiryById` function will also be added.
    -   **`api/orderApi.ts`**: A new function `checkoutCatering(inquiry, token)` will be added.
    -   **`api/mock.ts`**: Handlers for `POST /api/inquiries/:id/quote`, `GET /api/inquiries/:id`, and `POST /api/orders/checkout-catering` will be implemented to manage the state of quotes and create orders from them.

-   **Component Creation (`components/QuoteFormModal.tsx`):**
    -   A new modal component will be created for providers to enter the quote amount and expiration.

-   **Component Refactoring:**
    -   **`components/ConversationModal.tsx`**: Will be enhanced to show the "Send Formal Quote" button to providers, render the new quote message type, and display the "Accept & Pay" button for customers.
    -   **`components/CheckoutPage.tsx`**: Will be refactore to handle a new "catering checkout" mode. When loaded with an `inquiryId` in its route parameters, it will fetch the inquiry, display a simplified summary based on the quote, and use the new `checkoutCatering` API on submission.
    -   **`App.tsx`**: The router will be updated to pass the `inquiryId` to the `CheckoutPage`.
