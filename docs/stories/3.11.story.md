# Story 3.11: AI-Powered "Recommended For You" Collection

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a logged-in Customer, I want to see a personalized collection of "Recommended For You" kitchens on the homepage, so that I can discover new providers that match my tastes without having to search.

---

### Acceptance Criteria:

1.  **Given** a user is logged in and on the `HomePage`'s "Explore" tab.
2.  **When** the page loads, **Then** a new "Recommended For You" collection must appear above the "Top Rated" section.
3.  **Given** the user is logged out, **Then** this collection must not be visible.
4.  **Given** the recommendations are displayed, **Then** they must be based on the user's past interactions (orders, follows) and should not include kitchens they've already ordered from or followed.
5.  **Given** a user performs a search or applies a filter, **Then** the "Recommended For You" collection should be hidden, along with other curated collections.

---

### Technical Specification:

-   **AI Service (`services/geminiService.ts`):** A new function `getRecommendedProviders` has been created to call a new backend endpoint (`/api/ai/recommendations`) that simulates AI-based recommendations.
-   **Mock API (`api/mock.ts`):** A new handler for `POST /api/ai/recommendations` has been implemented. It takes a user object and a list of all providers, and returns a filtered, sorted list of recommended providers based on the user's interaction history (orders and follows).
-   **Component (`components/HomePage.tsx`):**
    -   Has been updated to fetch these recommendations for logged-in users.
    -   A new state `recommendedProviders` stores the results.
    -   A new `<section>` is conditionally rendered on the "Explore" tab to display the `MealProviderCard`s for the recommended providers.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The `HomePage` now displays a personalized "Recommended For You" collection for logged-in users.
-   [x] The mock API correctly simulates personalized recommendations.
-   [x] The new collection is hidden for logged-out users or when filters/search are active.
-   [x] The application remains fully functional.
