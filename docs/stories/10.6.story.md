# Story 10.6: Add Background Animation to Eid Theme

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done

---

### User Story:
As a user, when the Eid theme is active, I want to see a subtle background animation of falling moons and stars, so that the theme feels more complete and festive, similar to other special themes.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is activated by the Super Admin.
2.  **When** a user views any page of the application, **Then** a background animation of falling crescent moons and stars must be visible.
3.  **Given** the animation is active, **Then** it must be subtle and not interfere with the readability or usability of the main content.
4.  **Given** any other theme is active, **Then** this specific background animation must not be present (unless specified by that theme).

---

### Technical Specification:

-   **Theming System (`themes.ts`):**
    -   The `decorations` object for the 'Eid' theme configuration has been updated.
    -   The property `backgroundEffect` has been added with the value `'moon-and-stars'`.
    -   This leverages the existing animation logic already present in the `BackgroundDecorator.tsx` component.

-   **No Other Code Changes:**
    -   The rendering logic and CSS animations for the `moon-and-stars` effect were already implemented in a previous story. This change only involves activating that feature for the 'Eid' theme.
