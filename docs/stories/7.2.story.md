# Story 7.2: Provider Broadcast Announcements

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, I want to create and broadcast short announcements (e.g., "New menu item this weekend!", "Special 20% off on all thalis today!"), so I can directly engage my customer base and drive sales.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their main `DashboardPage`,
    **When** they view the page,
    **Then** a new panel or button for "Broadcasts" must be visible.

2.  **Given** a Provider clicks the "Create Broadcast" button,
    **When** the action is performed,
    **Then** a modal must appear with a textarea to compose an announcement message.

3.  **Given** the Provider is composing a message,
    **When** they view the modal,
    **Then** an "AI Assist" button must be available to help them refine their message for better engagement.

4.  **Given** the Provider clicks "Send Broadcast",
    **When** the announcement is saved,
    **Then** a confirmation message should appear, and the announcement is stored in the system.

5.  **Given** a Customer who has previously ordered from a Provider visits that kitchen's `MealProviderDetails` page,
    **When** the page loads,
    **Then** a new "Recent Updates" section should display the latest announcements from that Provider.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   A new interface has been created: `export interface Announcement { id: string; providerId: string; message: string; timestamp: string; }`.
    -   `announcements: Announcement[]` has been added to the `MealProvider` interface.

-   **API Service (`api/providerApi.ts`):**
    -   A new function `addAnnouncement(providerId: string, message: string, token: string): Promise<Announcement>` has been created.
    -   This makes a `POST` request to `/api/providers/:providerId/announcements`.

-   **Mock API (`api/mock.ts`):**
    -   `db.providers` in the mock database have been updated to include an empty `announcements: []` array.
    -   A handler for `POST /api/providers/:id/announcements` creates a new announcement object and adds it to the provider's `announcements` array.

-   **Provider UI (`components/DashboardPage.tsx`):**
    -   A new `BroadcastPanel.tsx` component has been added to the dashboard. This component contains a button to open the `BroadcastModal`.
    -   `BroadcastModal.tsx` contains the form for creating a new announcement and calls the `addAnnouncement` API function.

-   **Customer UI (`components/MealProviderDetails.tsx`):**
    -   A new "Recent Updates" section maps over the `provider.announcements` array and displays each announcement. It is only visible if there are announcements.
