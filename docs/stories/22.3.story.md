# Story 22.3: Responsive Overhaul for the HomePage

-   **Epic:** 22 (Mobile-First Responsive UI/UX Overhaul)
-   **Status:** Done

---

### User Story:
As a user on a mobile device, I want the homepage layout to be fully responsive, especially the grids and carousels, so that I can easily discover kitchens and browse collections on my small screen without layout issues.

---

### Visual Specification:

1.  **Provider Carousels ("Top Rated", "New This Week", etc.):**
    *   On desktop screens, the current 3-column grid layout will be preserved.
    *   On mobile screens, the grid will collapse into a single column. Each `MealProviderCard` will take the full width of the content area, creating a vertically scrollable list within each collection.

2.  **"All Kitchens" Grid:**
    *   On desktop screens, the 3-column grid layout will be preserved.
    *   On mobile screens, the grid will collapse into a single column, making it easy to scroll through all available providers.

3.  **Filter Section:**
    *   On mobile, the filter section will stack its internal elements vertically to be more readable and usable on a narrow screen.

---

### Acceptance Criteria:

1.  **Given** a user is on the `HomePage` on a small screen (mobile).
2.  **When** the page renders, **Then** all provider carousels must display as a single, vertical column.
3.  **Given** the user is on mobile, **Then** the main "All Kitchens" grid must also display as a single, vertical column.
4.  **Given** the user is on a large screen (desktop/tablet), **Then** the existing multi-column layouts for carousels and the main grid must be preserved.

---

### Technical Specification:

-   **Component (`components/ProviderCarousel.tsx`):**
    -   The main `div` that wraps the provider cards will have its `className` updated to use responsive grid classes. It will change from `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8` to ensure it collapses correctly.
    -   The title `h2` element is updated to `text-2xl sm:text-3xl` for better responsiveness on small screens.

-   **Component (`components/HomePage.tsx`):**
    -   The `div` that wraps the "All Kitchens" grid of `MealProviderCard`s will also be updated with responsive classes, changing from `grid-cols-3` to something like `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`.
    -   The section headers (`h2`) for "All Kitchens" and "Community Collections" are updated to `text-2xl sm:text-3xl` for better mobile layout.
    -   The filter panel's internal layout will be reviewed and updated with responsive classes (`md:grid-cols-4`) to ensure it stacks properly on mobile.

---
