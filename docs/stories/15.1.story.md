
# Story 15.1: Implement Super Admin Review Moderation System

-   **Epic:** 15 (Platform Governance & Trust Tools)
-   **Status:** Done

---

### User Story:
As a user (Customer or Provider), I want to be able to flag a review that I believe is inappropriate, unfair, or spam. As a Super Admin, I need a system to review and act upon these flagged reviews, so that I can maintain the integrity of the feedback system and ensure a fair and trustworthy marketplace for everyone.

---

### Acceptance Criteria:

1.  **Given** a logged-in user is viewing a `ReviewCard` on a `MealProviderDetails` page, **Then** a "Flag" icon must be visible.
2.  **Given** the user clicks the "Flag" icon, **Then** an API call is made to mark the review as flagged, and the icon's state changes to "Flagged" to provide feedback.
3.  **Given** a Super Admin is on their `SuperAdminDashboard`, **Then** a new "Review Moderation Queue" panel must be visible.
4.  **Given** the moderation panel is visible, **Then** it must display a list of all reviews from across the platform that have `isFlagged: true`.
5.  **Given** the admin views a flagged review in the queue, **Then** they must see the review content, its author, the provider it was for, and two action buttons: "Dismiss Flag" and "Delete Review".
6.  **Given** the admin clicks "Dismiss Flag", **Then** the review's `isFlagged` status is set to `false`, and it is removed from the moderation queue.
7.  **Given** the admin clicks "Delete Review", **Then** the review is permanently removed from the provider's data and from the platform.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Review` interface will be updated to include `isFlagged?: boolean;` and `flaggedByUserId?: string;`.

-   **API Layer:**
    -   **`api/providerApi.ts`**: A new function, `flagReview(providerId, reviewId, token)`, will be created to call `PUT /api/providers/:providerId/reviews/:reviewId/flag`.
    -   **`api/adminApi.ts`**:
        -   A new function, `getFlaggedReviews(token)`, will call `GET /api/admin/reviews/flagged` to fetch all flagged reviews.
        -   A new function, `resolveReviewFlag(providerId, reviewId, action, token)`, will call `PUT /api/admin/reviews/resolve` to dismiss or delete a review.

-   **Mock API (`api/mock.ts`):**
    -   Handlers for all three new API endpoints will be implemented to simulate the flagging, fetching, and resolution logic by modifying the mock database.

-   **Component Creation (`components/ReviewModerationPanel.tsx`):**
    -   A new panel component for the Super Admin dashboard that fetches and displays flagged reviews and provides the UI for moderation actions.

-   **Component Refactoring:**
    -   **`components/MealProviderDetails.tsx`**: Will be updated to include the "Flag" button on review cards for logged-in users and the handler to call the `flagReview` API.
    -   **`components/SuperAdminDashboard.tsx`**: Will be updated to include the new `ReviewModerationPanel`.

-   **Constants (`constants.tsx`):**
    -   A new `FlagIcon` will be added.
