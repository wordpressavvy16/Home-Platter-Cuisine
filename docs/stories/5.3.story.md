# Story 5.3: Verified Purchase Badges on Reviews

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Customer, when I am reading reviews for a kitchen, I want to see a "Verified Purchase" badge on reviews submitted by users who have actually ordered from that kitchen, so that I can trust the feedback is authentic and make more confident decisions.

---

### Acceptance Criteria:

1.  **Given** a Customer submits a review through the `ProfilePage` for a `DELIVERED` order.
2.  **When** the review is saved to the system, **Then** it must be automatically marked as a "verified" review.
3.  **Given** a user is viewing reviews on a `MealProviderDetails` page.
4.  **When** a review is from a verified purchase, **Then** a clear and distinct "Verified Purchase" badge must be displayed on that `ReviewCard`.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Review` interface has been updated to include a new optional boolean field: `isVerifiedPurchase?: boolean;`.

-   **API Layer (`api/mock.ts`):**
    -   The mock handler for `POST /api/providers/:id/reviews` has been updated to automatically set `isVerifiedPurchase: true` on all newly created reviews. This simulates the backend logic of tying a review to a completed order.

-   **UI Component (`components/ReviewCard.tsx`):**
    -   The component has been enhanced to conditionally display a "Verified Purchase" badge.
    -   If `review.isVerifiedPurchase` is `true`, a badge with a shield icon and text is rendered within the card's header.
