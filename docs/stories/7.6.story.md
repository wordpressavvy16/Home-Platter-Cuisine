# Story 7.6: Provider-Set Order Threshold Discounts

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, I want to be able to set up automatic discounts that apply when a customer's order subtotal reaches a certain amount (e.g., "10% off on all orders over ₹500"), so that I can incentivize customers to place larger orders and increase my average order value.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `EditProfilePage`,
    **When** they view the page,
    **Then** a new section for "Automatic Order Discounts" must be visible.

2.  **Given** the Provider is managing these discounts,
    **When** they configure the settings,
    **Then** they must be able to define a minimum order amount (threshold) and a discount percentage. For this story, we will support one active threshold discount at a time per provider.

3.  **Given** a Customer is adding items to their cart from a provider who has set up this discount,
    **When** their subtotal for that provider crosses the specified threshold,
    **Then** the discount must be automatically applied to their cart.

4.  **Given** a discount has been automatically applied,
    **When** the customer views their `CartModal` or the `CheckoutPage`,
    **Then** the order summary must clearly show a line item for the "Volume Discount" or "Order Discount," and the final total must reflect this.

5.  **Given** a customer removes an item and their subtotal drops below the threshold,
    **When** their cart updates,
    **Then** the automatic discount must be removed.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Update the `MealProvider` interface to include a new optional object: `orderThresholdDiscount?: { threshold: number; percentage: number; };`.

-   **API Layer (`api/mock.ts`):**
    -   The `PUT /api/providers/:id` endpoint will correctly handle saving the new `orderThresholdDiscount` object when the provider's profile is updated.

-   **Provider UI (`components/EditProfilePage.tsx`):**
    -   Add a new UI section for "Automatic Order Discounts" with number inputs for "Minimum Order Amount" and "Discount Percentage".
    -   The `handleSubmit` function will include this new object in the profile update payload.

-   **Cart & Checkout UI (`components/CartModal.tsx`, `components/CheckoutPage.tsx`):**
    -   Both components will now fetch the list of all providers to check for discount rules.
    -   They will calculate a final total by iterating through the `groupedCart`. For each provider's subtotal, they will check if an automatic threshold discount applies.
    -   The order summary UI in both components will be updated to display a "Volume Discount" line item if one is applied.
    -   On the `CheckoutPage`, this automatic discount will only apply if a manual coupon code for that provider has not already been used.
