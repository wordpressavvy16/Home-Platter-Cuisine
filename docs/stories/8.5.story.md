# Story 8.5: AI-Suggested Replies for Customer Reviews

-   **Epic:** 8 (Automated Customer Support & Conflict Resolution)
-   **Status:** Done

---

### User Story:
As a Provider, when replying to a customer review, I want to see AI-generated reply suggestions, so that I can respond quickly and professionally, improving my engagement and saving time.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage` and views the "Customer Feedback" panel.
2.  **When** they click "Reply" on a review, the `ReplyFormModal` must open.
3.  **Given** the `ReplyFormModal` is open, **Then** a new "Generate Suggestions with AI" button must be visible within the form.
4.  **Given** the Provider clicks the "Generate Suggestions" button, **Then** a loading state must appear, and an API call is made to an AI endpoint with the review's rating and comment text.
5.  **Given** the AI analysis is complete, **Then** 2-3 context-aware reply suggestions must be displayed as clickable buttons inside the modal.
6.  **Given** the Provider clicks on a suggestion button, **Then** the main reply textarea must be populated with that text, and the suggestion buttons should be hidden.

---

### Technical Specification:

-   **AI Guardrails (Non-Negotiable):**
    -   The AI's system instruction must enforce a professional, customer-centric tone.
    -   For **positive reviews (4-5 stars):** Generate appreciative and specific replies.
    -   For **mixed reviews (3 stars):** Generate replies that acknowledge both positive and negative points and politely seek more information.
    -   For **negative reviews (1-2 stars):** Generate empathetic, apologetic replies that aim to de-escalate and take the conversation to a private channel. The AI must **never** be defensive or argumentative.
    -   The AI must **never** make specific promises (e.g., "We will give you a free meal").

-   **AI Service (`services/geminiService.ts`):**
    -   A new function will be created: `getReviewReplySuggestions(review: Review, token: string): Promise<string[]>`.
    -   This function will make a `POST` request to a new secure backend endpoint: `/api/ai/review-reply-suggestions`.

-   **Mock API (`api/mock.ts`):**
    -   A new mock handler for `POST /api/ai/review-reply-suggestions` will be implemented.
    -   It will inspect the `rating` from the incoming review data and return a plausible, hardcoded array of appropriate string replies for testing.

-   **Component (`components/ReplyFormModal.tsx`):**
    -   The component will be enhanced with new state variables to manage `suggestions` and `isLoadingSuggestions`.
    -   A new "Generate Suggestions with AI" button will be added.
    -   The `onClick` handler for this button will call the `getReviewReplySuggestions` service.
    -   The component will render a loading indicator or clickable suggestion buttons based on the state.
    -   Clicking a suggestion will update the `replyText` state.

-   **No Data Model Changes:** This feature can be implemented without changes to the existing `Review` or `MealProvider` types.
