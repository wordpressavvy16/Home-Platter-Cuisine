# Story 3.4: Curated Homepage Collections

-   **Epic:** 3 (Customer Marketplace & Discovery Engine)
-   **Status:** Done

---

### User Story:
As a Customer, when I visit the homepage, I want to see curated collections like "Top Rated Kitchens" and "New on HomePlate," so that I can easily discover popular and new providers without having to search.

---

### Acceptance Criteria:

1.  **Given** a user is on the `HomePage`,
    **When** the page loads,
    **Then** new sections titled "Top Rated Kitchens" and "New This Week" must be visible above the main "All Kitchens" grid.

2.  **Given** the "Top Rated Kitchens" section,
    **When** it is displayed,
    **Then** it must show a horizontal list of the top 4-5 providers, sorted in descending order of their `rating`.

3.  **Given** the "New This Week" section,
    **When** it is displayed,
    **Then** it must show a horizontal list of the most recently joined providers, sorted in descending order of their `joinDate`.

4.  **Given** a user views these new sections,
    **When** they see the provider cards,
    **Then** the cards should be fully interactive, navigating to the provider's detail page upon click, just like the main grid.

---

### Technical Specification:

-   **Component Creation (`components/ProviderCarousel.tsx` - New):**
    -   A new, reusable component `ProviderCarousel` has been created, which accepts a `title`, `providers`, and an `onSelectProvider` function as props.
    -   This component renders a title and a horizontally-scrollable list of `MealProviderCard` components.

-   **Component Refactoring (`components/HomePage.tsx`):**
    -   Two new `useMemo` hooks derive the curated lists from the main `providers` state:
        -   `topRatedProviders`: Sorts `providers` by `rating` (descending) and takes the top 5.
        -   `newestProviders`: Sorts `providers` by `joinDate` (descending) and takes the top 5.
    -   The `ProviderCarousel` component is instantiated twice for these two lists.
    -   The main grid title has been changed to "All Kitchens".

-   **Constants (`constants.tsx`):**
    -   A new `FireIcon` has been added for use in the "Top Rated Kitchens" collection.

-   **No API Changes:** This is a frontend-only enhancement. All necessary data (`rating`, `joinDate`) is already available from the existing `getProviders` API call.
