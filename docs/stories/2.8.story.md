# Story 2.8: Provider Menu Categorization

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to assign a category to each of my menu items (e.g., "Appetizers," "Main Course"), so that my menu is organized and easier for customers to browse. As a Customer, I want to see a provider's menu grouped by these categories.

---

### Acceptance Criteria:

1.  **Given** a Provider is adding or editing a meal in the `MealFormModal`,
    **When** they view the form,
    **Then** a new text input field for "Category" must be available.

2.  **Given** a Provider saves a meal with a category,
    **When** the data is stored,
    **Then** the category string must be saved with the meal's data.

3.  **Given** a Provider is viewing their menu on the `ManageMenuPage`,
    **When** their menu has items with categories,
    **Then** the meals should be visually grouped and displayed under their respective category headings.

4.  **Given** a Customer is viewing a menu on the `MealProviderDetails` page,
    **When** the menu has items with categories,
    **Then** the meals must be displayed grouped under their category headings (e.g., a large "Main Course" title followed by the relevant meal cards).

5.  **Given** a menu has items with and without categories,
    **When** it is displayed to either a Provider or Customer,
    **Then** items without a category should be grouped under a default heading like "Other".

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Meal` interface has been updated to include a new optional field: `category?: string;`.

-   **Provider UI (`components/MealFormModal.tsx`):**
    -   A new `<input type="text">` for the `category` has been added to the form.

-   **Provider UI (`components/ManageMenuPage.tsx`):**
    -   The rendering logic has been refactored to first group meals by category into an object and then iterate over this object to render grouped lists.

-   **Customer UI (`components/MealProviderDetails.tsx`):**
    -   The same grouping and rendering logic as in `ManageMenuPage.tsx` has been applied to the menu display section.

-   **Mock API (`api/mock.ts`):**
    -   The default `MEAL_PROVIDERS_DEFAULT` data has been updated to include a `category` field on several `Meal` objects for testing.
