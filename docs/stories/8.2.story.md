# Story 8.2: AI-Suggested Replies for Providers

-   **Epic:** 8 (Automated Support & Conflict Resolution)
-   **Status:** Done

---

### User Story:
As a Provider, when I open a new message from a customer, I want to see AI-generated reply suggestions, so that I can respond quickly and efficiently, especially during busy times, while still having full control over the final message.

---

### Acceptance Criteria:

1.  **Given** a Provider opens the `MessagingModal` to view a conversation with a new, unread customer message.
2.  **When** the modal loads, **Then** an API call must be made to a new AI endpoint, sending the customer's message for analysis.
3.  **Given** the AI analysis is in progress, **Then** a subtle loading indicator should be visible in a new "Suggested Replies" area above the message input field.
4.  **Given** the AI analysis is complete, **Then** 1-3 relevant, context-aware reply suggestions must be displayed as clickable buttons.
5.  **Given** the Provider clicks on a suggestion button, **Then** the message input field is populated with the suggestion's text, and the suggestion buttons are hidden.
6.  **Given** the Provider sends a reply, **Then** the suggestion buttons for that message should disappear.

---

### Technical Specification:

-   **AI Service (`services/geminiService.ts`):**
    -   A new function has been created: `getReplySuggestions(messageText: string, token: string): Promise<string[]>`.
    -   This function makes a `POST` request to a secure backend endpoint: `/api/ai/reply-suggestions`.

-   **Mock API (`api/mock.ts`):**
    -   A mock handler for `POST /api/ai/reply-suggestions` has been implemented to return a hardcoded array of plausible string replies for testing, based on message keywords.

-   **Component (`components/MessagingModal.tsx`):**
    -   New state variables `suggestions` and `isLoadingSuggestions` have been added.
    -   A `useEffect` hook triggers when the modal opens or messages change. It checks if the last message is from a customer and, if so, calls the `getReplySuggestions` service.
    -   A new "Suggested Replies" section is rendered above the message input form, displaying a loader or clickable suggestion buttons as appropriate.
    -   The `onClick` handler for a suggestion button populates the input field and hides the suggestions.
