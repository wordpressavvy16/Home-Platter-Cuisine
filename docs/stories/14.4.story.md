# Story 14.4: Abstract API Layer for Production Readiness

-   **Epic:** 14 (Deployment & Operations)
-   **Status:** Done

---

### User Story:
As a Developer, I want to refactor the API service layer to remove its direct dependency on the mock router and prepare it to communicate with a real, production backend via environment variables, so that the application can be seamlessly switched from a local simulation to a live environment.

---

### Acceptance Criteria:

1.  A new central API client module (`api/client.ts`) must be created.
2.  The new client must use a simulated environment variable (`USE_MOCK_API`) to decide whether to route requests to the `mockApiRouter` or to a real backend URL using `fetch`.
3.  All existing API service files (`authApi.ts`, `orderApi.ts`, `providerApi.ts`, `userApi.ts`, `adminApi.ts`, `supportApi.ts`, `inquiryApi.ts`, `collectionApi.ts`) and the `geminiService.ts` must be refactored to use the new `apiClient` instead of calling `mockApiRouter` directly.
4.  The application must continue to function identically with no regressions when the mock API is enabled.
5.  The architecture is now prepared for the "Go-Live & Fortification" phase of the project roadmap, allowing for an easy switch to a live backend.

---

### Technical Specification:

-   **Component Creation (`api/client.ts`):**
    -   Create a new file `api/client.ts`.
    -   This file will export a single asynchronous function `apiClient(path: string, options?: RequestInit): Promise<Response>`.
    -   Inside the file, define a constant `const USE_MOCK_API = true;` to simulate an environment variable. This ensures the application continues to use the mock backend by default.
    -   The `apiClient` function will check this constant. If `true`, it will `return mockApiRouter(path, options)`. If `false`, it will construct a full URL and `return fetch(url, options)`.

-   **API Layer Refactoring:**
    -   Systematically go through every file in the `api/` directory and the `services/geminiService.ts` file.
    -   In each file, replace the import of `mockApiRouter` from `./mock` with an import of `apiClient` from `./client`.
    -   Replace all calls from `mockApiRouter(...)` to `apiClient(...)`.
