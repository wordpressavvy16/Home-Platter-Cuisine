# Story 8.1: AI-Powered Customer Support Chatbot

-   **Epic:** 8 (Automated Customer Support & Conflict Resolution)
-   **Status:** Done

---

### User Story:
As a user (either a Customer or a Provider), I want to access a helpful chatbot from anywhere in the application, so that I can get instant answers to my questions without having to search or wait for human support.

---

### Acceptance Criteria:

1.  **Given** a user is on any page of the application,
    **When** they look at the screen,
    **Then** a floating "Help" button must be visible in a fixed position (e.g., bottom-right corner).

2.  **Given** the user clicks the floating "Help" button,
    **When** the action is performed,
    **Then** a chat window must open, and the help button should change to a "Close" icon.

3.  **Given** the chat window is open,
    **When** the user views it,
    **Then** it must display an initial welcome message from the bot (e.g., "Hello! How can I help you?").

4.  **Given** the user types a message and clicks "Send",
    **When** the message is sent to the AI,
    **Then** the bot's response must be streamed back in real-time, with the text appearing token-by-token.

5.  **Given** the bot is generating a response,
    **When** the user views the chat,
    **Then** a loading indicator must be visible while waiting for the response to complete.

6.  **Given** the user has a conversation with the bot,
    **When** they close and reopen the chat window within the same session,
    **Then** the conversation history must be preserved.

---

### Technical Specification:

-   **Widget Component (`components/SupportChatbotWidget.tsx`):**
    -   Create a new component that will be added to the root `App.tsx` layout.
    -   This component manages the `isOpen` state for the chatbot window.
    -   It renders the floating button and, when `isOpen` is true, renders the `SupportChatbot` component.

-   **Chat UI Component (`components/SupportChatbot.tsx`):**
    -   Create a new component that represents the chat window itself.
    -   It will manage the state for the `messages: ChatMessage[]` array and the user's current `input`.
    -   It will render the list of messages, distinguishing between 'USER' and 'MODEL' roles for styling.
    -   It will include a form with an input field and a send button.

-   **Chat Service (`services/chatService.ts` - New File):**
    -   Create a new service dedicated to handling the chat logic.
    -   This service will initialize the Gemini client (`new GoogleGenAI(...)`).
    -   It will create a persistent `Chat` instance using `ai.chats.create()` with a detailed `systemInstruction` defining the bot's persona and knowledge boundaries.
    -   It will expose a `sendMessageStream(message: string)` function that calls the `chat.sendMessageStream()` method and returns the async iterable response.

-   **Streaming Logic:**
    -   In `SupportChatbot.tsx`, the `handleSend` function will use a `for await...of` loop to iterate over the stream returned by `chatService.sendMessageStream`.
    -   Inside the loop, it will append the received `chunk.text` to the last message in the `messages` array (which will be the placeholder for the model's response), creating the real-time typing effect.

-   **Types & Constants:**
    -   Add a `ChatMessage` type to `types.ts`.
    -   Add new icons (`ChatBubbleIcon`, `PaperAirplaneIcon`, `XMarkIcon`, `RobotIcon`) to `constants.tsx`.
