# Story 8.3: Integrated Help Desk & Ticketing System

-   **Epic:** 8 (Automated Customer Support & Conflict Resolution)
-   **Status:** Done

---

### User Story:
As a user (Customer or Provider), I want a dedicated "Help & Support" section where I can create a formal support ticket for issues that the AI chatbot cannot resolve. As a Super Admin, I want a centralized dashboard to view, manage, and reply to all user-submitted tickets, so that I can provide structured and trackable human support.

---

### Acceptance Criteria:

1.  **Given** a logged-in user (Customer or Provider) is on their profile page, **Then** a "Help & Support" link must be available that navigates them to a new Help Center page.
2.  **Given** a user is on the Help Center page, **Then** they must see a list of their previously submitted support tickets and their statuses (e.g., 'OPEN', 'RESOLVED').
3.  **Given** a user is on the Help Center page, **Then** a "Create New Ticket" button must be available, which opens a modal for submitting a new support request with a subject, category, and description.
4.  **Given** a Super Admin is on their dashboard, **Then** a new "Support Tickets" panel must be visible, showing a summary and list of all tickets across the platform.
5.  **Given** the Super Admin views a ticket, **Then** they must be able to add a reply to the ticket's conversation thread and change its status.
6.  **Given** an admin replies to a ticket, **Then** the user who submitted the ticket must receive a notification.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   New interfaces `SupportTicket` and `TicketMessage` have been created to model the ticketing system.

-   **API Service (`api/supportApi.ts` - New File):**
    -   A new API service file has been created to handle all interactions with the `/api/support/*` endpoints, including creating, fetching, and updating tickets and messages.

-   **Mock API (`api/mock.ts`):**
    -   A new `db.supportTickets` array has been added to the mock database.
    -   Handlers for all new support API endpoints have been implemented. The message handler now generates a notification for the recipient upon a new reply.

-   **Component Creation:**
    -   `components/HelpPage.tsx`: A new page for users to view their tickets and create new ones.
    -   `components/TicketFormModal.tsx`: A modal for submitting new support tickets.
    -   `components/SuperAdminSupportPanel.tsx`: A new panel for the Super Admin dashboard to manage all tickets.
    -   `components/TicketConversationModal.tsx`: A reusable modal for both users and admins to view and reply to a ticket's message thread.

-   **Component Integration:**
    -   **`App.tsx`**: A new route `/help` has been added.
    -   **`ProfilePage.tsx`**: A "Help & Support" link/button has been added to navigate users to the new help page.
    -   **`SuperAdminDashboard.tsx`**: The new `SuperAdminSupportPanel` has been added to the dashboard layout.
