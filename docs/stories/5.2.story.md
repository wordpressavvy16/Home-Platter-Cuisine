# Story 5.2: Direct Customer-Provider Messaging

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Customer, I want to be able to send a direct message to a Provider regarding a specific order, so that I can ask clarifying questions about my meal or delivery. As a Provider, I want to receive and reply to these messages to offer better customer service.

---

### Acceptance Criteria:

1.  **Given** a Customer is viewing one of their orders on their `ProfilePage`,
    **When** the order status is active (e.g., 'CONFIRMED', 'PREPARING', 'OUT_FOR_DELIVERY'),
    **Then** a "Contact Provider" button must be visible.

2.  **Given** the Customer clicks "Contact Provider",
    **When** the action is performed,
    **Then** a messaging modal should appear, pre-populated with the context of the selected order.

3.  **Given** a Provider is on their `DashboardPage`,
    **When** they receive a new message from a customer,
    **Then** a new "Messages" panel should show that they have messages.

4.  **Given** the Provider clicks into their messages panel,
    **When** the view loads,
    **Then** they should see a list of conversation threads, organized by customer and order, and be able to open a modal to reply.

5.  **Given** a message is sent by either party,
    **When** the message is sent,
    **Then** the recipient must receive a notification.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   A new `Message` interface has been created: `{ id: string; senderId: string; text: string; timestamp: string; }`.
    -   The `Order` interface has been updated to include an optional `messages?: Message[]` array.

-   **Component Creation:**
    -   `components/MessagingModal.tsx`: A modal to display a conversation thread and allow sending messages.
    -   `components/MessagingPanel.tsx`: A new dashboard panel for providers to view and access their conversations.

-   **API Service (`api/orderApi.ts`):**
    -   A new function `sendMessageToOrder(orderId, messageData, token)` makes a `POST` request to `/api/orders/:orderId/messages`.

-   **Mock API (`api/mock.ts`):**
    -   A handler for `POST /api/orders/:id/messages` adds the message to the specified order's `messages` array and generates a notification for the recipient.

-   **Component Integration:**
    -   **`ProfilePage.tsx`**: A "Contact Provider" button on active orders opens the `MessagingModal`.
    -   **`DashboardPage.tsx`**: The `MessagingPanel` has been added as a draggable panel.
    -   **`Header.tsx`**: Notifications link to the `ProfilePage` for customers and `DashboardPage` for providers.
