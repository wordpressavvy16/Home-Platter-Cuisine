# Story 5.4: Provider Public Replies to Reviews

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Provider, I want to be able to write and publish a public reply to a customer's review, so that I can engage with feedback, thank my customers, and address any concerns for all future visitors to see.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage`.
2.  **When** they view their reviews, **Then** a "Reply" button must be visible on any review that does not already have a reply.
3.  **Given** a Provider clicks the "Reply" button.
4.  **When** the action is performed, **Then** a modal must open, showing the original customer comment and a textarea for the provider's response.
5.  **Given** the Provider submits their reply, **Then** the reply text is saved and associated with that specific review.
6.  **Given** a Customer is viewing a review on a `MealProviderDetails` page that has a provider reply, **Then** the provider's reply must be clearly visible below the original customer comment, visually distinguished as a response from the chef.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `Review` interface has been updated to include an optional object: `providerReply?: { text: string; timestamp: string; };`.

-   **API Service (`api/providerApi.ts`):**
    -   A new function, `addReplyToReview(providerId, reviewId, replyText, token)`, has been created to make a `POST` request to `/api/providers/:providerId/reviews/:reviewId/reply`.

-   **Mock API (`api/mock.ts`):**
    -   A handler for the new `reply` endpoint has been implemented. It finds the specified review in the mock DB and adds the `providerReply` object.
    -   A sample replied review has been added to the default data for testing.

-   **Component Creation:**
    -   `components/ReplyFormModal.tsx`: A new modal component to handle the input and submission of the provider's reply.
    -   `components/ReviewManagementPanel.tsx`: A new panel for the `DashboardPage` that fetches and lists all reviews for the provider, including the "Reply" button for each.

-   **Component Refactoring:**
    -   `components/DashboardPage.tsx`: The new `ReviewManagementPanel` has been added to the layout.
    -   `components/ReviewCard.tsx`: The component has been updated to conditionally render the `providerReply` in a visually distinct section if it exists.
