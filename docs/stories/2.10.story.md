# Story 2.10: Customizable Provider Dashboard

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to rearrange the panels on my dashboard via drag-and-drop, so I can create a personalized layout that prioritizes the information most important to my workflow.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage`,
    **When** they hover over a panel (e.g., "Manage Menu", "My Subscription"),
    **Then** a drag handle should become visible, indicating the panel is movable.

2.  **Given** a Provider drags a panel and drops it in a new position,
    **When** the action is complete,
    **Then** the dashboard layout must visually update to reflect the new arrangement of panels.

3.  **Given** the Provider has rearranged their dashboard,
    **When** they refresh the page or log in again,
    **Then** their custom layout must be saved and persist across sessions.

4.  **Given** the provider wants to return to the original layout,
    **When** they view the dashboard,
    **Then** a "Reset Layout" button must be available. Clicking it should restore the dashboard to its default configuration.

---

### Technical Specification:

-   **Library Integration:**
    -   This feature will require a drag-and-drop library. We will use `dnd-kit`, a modern and accessible library for React. This will need to be added to the project's dependencies (simulated via import map in `index.html`).

-   **Data Model (`types.ts`):**
    -   Update the `MealProvider` interface to include an optional array of strings: `dashboardLayout?: string[];`. This array will store the unique IDs of the dashboard panels in their desired order.

-   **API Service (`api/providerApi.ts`):**
    -   Create a new function `updateProviderDashboardLayout(providerId: string, layout: string[], token: string): Promise<MealProvider>`.
    -   This will make a `PUT` request to `/api/providers/:providerId/dashboard-layout`.

-   **Mock API (`api/mock.ts`):**
    -   Implement a handler for `PUT /api/providers/:id/dashboard-layout`. This handler will find the specified provider and update their `dashboardLayout` array.

-   **Component Refactoring (`components/DashboardPage.tsx`):**
    -   The component will be significantly refactored to support drag-and-drop.
    -   It will maintain a state variable, `panelOrder: string[]`, initialized from `provider.dashboardLayout` or a default array if none is saved.
    -   The main grid will be wrapped in `dnd-kit` provider components (`DndContext`).
    -   Each dashboard panel/button will be wrapped in a new `DraggablePanel` component that handles the `useDraggable` logic.
    -   An `onDragEnd` handler will update the `panelOrder` state and call the `updateProviderDashboardLayout` API to save the new layout.
    -   A "Reset Layout" button will be added that clears the `dashboardLayout` on the provider object and resets the local state to default.
