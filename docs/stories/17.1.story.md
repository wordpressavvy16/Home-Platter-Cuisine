# Story 17.1: Frontend - Connect to Live Provider & Product Data

-   **Epic:** 17 (Live Backend - Provider & Product Catalog Migration)
-   **Status:** Done

---

### User Story:
As a Frontend Developer, I need to update the application to fetch all provider and menu data from the new live backend services, so that the marketplace displays real, persistent data instead of the current mock data.

---

### Acceptance Criteria:

1.  The application's API calls for fetching providers and their details (e.g., `/api/providers`, `/api/providers/:id`) are now directed to the live backend endpoint (`https://api.homeplatter.com`) instead of the internal mock server.
2.  All other API calls (for orders, AI features, etc.) must continue to function by routing to the mock server to prevent breaking the application.
3.  The `api/client.ts` "switch" logic is updated to selectively route all provider-related requests to the live backend.
4.  The `HomePage`, `ProviderDetailsPage`, and all other components that display provider or menu information now work seamlessly with the data from the live backend.

---

### Technical Specification:

-   **API Client (`api/client.ts`):**
    -   The `apiClient` function has been refactored to be path-aware.
    -   It now checks if an incoming request path `startsWith('/api/providers')`.
    -   If it's a provider-related request, it sets a local `useMock` flag to `false` and makes a real `fetch` call to the production `API_BASE_URL`.
    -   For all other non-auth request paths, the `useMock` flag remains `true`, and the request is routed to the internal `mockApiRouter`.

-   **No other code changes are required.** The existing `providerApi.ts` and UI components already use the `apiClient`, so they will inherit this new routing behavior automatically.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The `api/client.ts` now selectively routes provider requests to the live backend.
-   [x] The rest of the application remains functional by continuing to use the mock API.
-   [x] The application's core marketplace pages now make real network requests for provider data.
-   [x] Story status updated to 'Done' in `changelog.md` and the Epic 17 PRD file.
