# Story 20.1: Provider Tiffin Plan Management

-   **Epic:** 20 (Tiffin Service Subscription Engine)
-   **Status:** Done

---

### User Story:
As a Provider, I want to create, manage, and display weekly/monthly tiffin plans from my dashboard, so I can offer recurring meal services to my customers.

---

### Acceptance Criteria:

1.  A new draggable panel titled "Tiffin Plans" is available on the `DashboardPage`.
2.  The panel contains a "Create New Plan" button that opens a `TiffinPlanFormModal`.
3.  The modal form includes fields for Plan Name, Duration (Weekly/Monthly), Price, and a detailed Description.
4.  The modal includes a "Sample Weekly Menu" section, which is a grid (Lunch/Dinner vs. Mon-Sun) where the provider can type in tentative meal names for each slot.
5.  After saving, the new plan is displayed as a summary card within the "Tiffin Plans" panel on the dashboard.
6.  Each plan card on the dashboard has "Edit" and "Delete" buttons that allow the provider to manage their existing plans.
7.  The system prevents a provider from saving a plan without a name, duration, and price.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Create a new `SampleMenu` interface: `{ monday: { lunch?: string; dinner?: string; }, tuesday: { ... } ... }`.
    -   Create a new `TiffinPlan` interface: `{ id: string; name: string; duration: 'WEEKLY' | 'MONTHLY'; price: number; description: string; sampleMenu: SampleMenu; }`.
    -   Update the `MealProvider` interface to include an optional array: `tiffinPlans?: TiffinPlan[];`.

-   **API Layer (`api/providerApi.ts` & `api/mock.ts`):**
    -   Create new API functions in `providerApi.ts`:
        -   `createTiffinPlan(providerId, planData, token)`
        -   `updateTiffinPlan(providerId, planId, planData, token)`
        -   `deleteTiffinPlan(providerId, planId, token)`
    -   Implement mock handlers in `mock.ts` for these new endpoints to perform CRUD operations on the `tiffinPlans` array within the provider's data.

-   **Component Creation:**
    -   `components/TiffinPlanManager.tsx`: A new draggable panel for the dashboard. It will fetch and display the provider's tiffin plans and include the "Create New Plan" button.
    -   `components/TiffinPlanFormModal.tsx`: A new modal containing the form for creating and editing tiffin plans, including the sample menu grid.

-   **Component Integration (`components/DashboardPage.tsx`):**
    -   Add `'tiffinPlans'` to the `DEFAULT_LAYOUT` array.
    -   Update the `dashboardPanels` object to include a new entry for `'tiffinPlans'` that renders the `TiffinPlanManager` component.
