# Story 5.7: Shareable Provider Profiles

-   **Epic:** 5 (Trust, Reviews & Community Engagement)
-   **Status:** Done

---

### User Story:
As a Customer, I want to easily share a link to my favorite kitchen's profile with my friends and family, so that I can recommend great food and help the provider get more business.

---

### Acceptance Criteria:

1.  **Given** a user is on a `MealProviderDetails` page.
2.  **When** they view the page header, **Then** a "Share" icon/button must be visible.
3.  **Given** the user is on a device that supports the Web Share API (most mobile devices).
4.  **When** they click the "Share" button, **Then** the browser's native sharing dialog must open, pre-populated with the kitchen's name, a short description, and a direct link to the page.
5.  **Given** the user is on a device that does not support the Web Share API (most desktops).
6.  **When** they click the "Share" button, **Then** the direct link to the provider's page must be copied to their clipboard.
7.  **Given** the link has been copied to the clipboard, **Then** a small, temporary confirmation message (e.g., "Link Copied!") must appear to provide user feedback.

---

### Technical Specification:

-   **Component (`components/MealProviderDetails.tsx`):**
    -   A new "Share" button has been added to the page header area, next to the "Follow" button.
    -   A new state, `isLinkCopied`, has been added to manage the visibility of the confirmation message.
    -   A `handleShare` async function has been implemented. This function checks for the existence of `navigator.share`.
        -   If `navigator.share` is available, it is called with the provider's details.
        -   If not, it falls back to `navigator.clipboard.writeText(window.location.href)`.
        -   The function includes error handling and sets the `isLinkCopied` state upon successful copying.

-   **Constants (`constants.tsx`):**
    -   A new `ShareIcon` SVG has been added to represent the share action visually.

-   **No API or Data Model Changes:**
    -   This is a client-side feature that leverages browser APIs and does not require any backend changes.
