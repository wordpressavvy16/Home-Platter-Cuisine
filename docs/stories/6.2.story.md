# Story 6.2: AI-Powered Meal Description Generator

-   **Epic:** 6 (AI-Powered Business Intelligence Suite for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, when I am adding or editing a meal, I want an AI-powered assistant that can generate a delicious and enticing description for my dish based on its name and type, so that I can create high-quality menu listings quickly and attract more customers.

---

### Acceptance Criteria:

1.  **Given** a Provider is in the `MealFormModal` to add or edit a meal.
2.  **When** they have entered a "Meal Name" (e.g., "Shahi Paneer Thali"), **Then** an "Auto-generate with AI" button must appear next to the "Description" field.
3.  **Given** the Provider clicks the "Auto-generate with AI" button, **Then** a loading state must be shown, and an API call is made to an AI endpoint with the meal's name and type.
4.  **Given** the AI successfully generates a description, **Then** the "Description" textarea must be automatically populated with the AI-generated text.
5.  **Given** the description is populated, **Then** the provider can either use it as-is or edit it further before saving the meal.

---

### Technical Specification:

-   **Component (`components/MealFormModal.tsx`):**
    -   A new state variable, `isGeneratingDescription`, will be added to manage the loading state of the AI generation.
    -   An "Auto-generate with AI" button will be added to the form, likely next to the "Description" label. This button will be disabled if the meal name is empty.
    -   An `onClick` handler for this button will be created. It will call a new AI service function, `generateMealDescription`, and update the meal's description state with the result.

-   **AI Service (`services/geminiService.ts`):**
    -   A new function, `generateMealDescription(mealName: string, mealType: MealType, token: string): Promise<{ description: string }>`, will be created.
    -   This function will call a new backend endpoint: `POST /api/ai/meal-description`.

-   **Mock API (`api/mock.ts`):**
    -   A mock handler for `POST /api/ai/meal-description` will be implemented.
    -   This handler will receive the meal name and type and return a plausible, hardcoded, descriptive string for testing purposes.
