# Story 2.14: Provider-Featured Meals

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to select a few of my meals to "feature" at the top of my menu, so that I can highlight my best-selling dishes, new items, or daily specials. As a Customer, I want to see these featured items first to quickly discover the best of what a kitchen has to offer.

---

### Acceptance Criteria:

1.  **Given** a Provider is on the `ManageMenuPage`,
    **When** they view their meal cards (`ManageableMealCard`),
    **Then** each card must have a "Feature" button or icon (e.g., a star).

2.  **Given** a Provider attempts to feature more than a set limit of items (e.g., 3),
    **When** they feature a new item,
    **Then** the oldest featured item is automatically un-featured to maintain the limit.

3.  **Given** a Customer is viewing a `MealProviderDetails` page,
    **When** the provider has featured items,
    **Then** a new "Featured Items" section must appear at the very top of the menu.

4.  **Given** a meal is featured,
    **When** a Customer views its `MealCard`,
    **Then** it must display a clear visual badge (e.g., "Chef's Special").

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Update the `Meal` interface to include `isFeatured?: boolean;` and `featuredAt?: string;`.

-   **API Layer (`api/mock.ts`):**
    -   The `PUT /api/providers/:id/menu/:mealId` endpoint will be updated to handle the logic for featuring meals. When a meal is featured, it will check if the provider has reached the feature limit (3). If so, it will find the meal with the oldest `featuredAt` timestamp and un-feature it before featuring the new one.

-   **Provider UI (`components/ManageableMealCard.tsx`):**
    -   A new "Feature" button with a star icon will be added.
    -   Clicking this button will call the `onUpdateMeal` prop, toggling the `isFeatured` status of the meal.

-   **Customer UI (`components/MealProviderDetails.tsx`):**
    -   A new "Featured Items" section will be added at the top of the menu display.
    -   This section will render `MealCard` components for any meal where `isFeatured` is `true`.
    -   The main menu rendering logic will be updated to exclude featured items to prevent duplication.

-   **Customer UI (`components/MealCard.tsx`):**
    -   The component will be updated to conditionally render a "Chef's Special" badge if `meal.isFeatured` is `true`.
