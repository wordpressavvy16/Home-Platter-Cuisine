# Story 10.2.2: Enhance Christmas Theme Animation (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.2

---

### User Story:
As a user, when the Christmas theme is active, I want to see a background animation of various festive elements like Santa hats, bells, and trees in addition to the snow, to create a richer and more immersive holiday experience.

---

### Acceptance Criteria:

1.  **Given** the "Christmas" festive theme is activated by the Super Admin.
2.  **When** a user views any page of the application, **Then** the existing background snowfall animation must still be present.
3.  **Given** the animation is active, **Then** in addition to snowflakes, there must be other gently falling festive elements, including Santa hats, Christmas bells, trees, and ornaments.
4.  **Given** the new elements are falling, **Then** they must use a different, gentle falling/rotating animation to create a visually distinct layer from the drifting snowflakes.
5.  **Given** the enhanced animation is active, **Then** it must remain subtle, elegant, and not interfere with the main content's readability.

---

### Technical Specification:

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   A new `backgroundEffect` case, `'christmas-mix-fall'`, has been added.
    -   This new logic renders two sets of particles:
        -   The original array of 50 `❄️` emojis using the `animate-snowfall` class.
        -   A new array of ~15 mixed elements (Santa hats, bells, trees, ornaments) using the `animate-gentle-fall` class to add a subtle rotation.
    -   The component combines both arrays into a single list of particles to be rendered.

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface's `backgroundEffect` type has been updated to include the new `'christmas-mix-fall'` option.
    -   The 'Christmas' theme object's `backgroundEffect` property has been changed from `'snowfall'` to the new `'christmas-mix-fall'`.

-   **Constants (`constants.tsx`):**
    -   New SVG components, `SantaHatIcon` and `ChristmasBellsIcon`, have been created to provide high-quality, theme-consistent icons for the new animation.
