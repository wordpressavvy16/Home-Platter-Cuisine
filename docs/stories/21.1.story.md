# Story 21.1: Customer Achievement & Badge System

-   **Epic:** 21 (Community & Gamification Engine)
-   **Status:** Done

---

### User Story:
As a Customer, I want to earn badges and achievements for completing certain actions on the platform, and display them on my profile, so that I feel rewarded for my engagement and can showcase my status in the community.

---

### Acceptance Criteria:

1.  A new `Badge` data type is defined, including an ID, name, description, and an associated icon component.
2.  The `User` data model is updated to store an array of earned badge IDs.
3.  A new "Achievements" tab is added to the `ProfilePage`.
4.  This "Achievements" tab displays a visually engaging grid of all badges the user has earned, showing each badge's icon, name, and description.
5.  The backend (mock) is updated to automatically award badges when specific actions are completed. For this story, the system will award:
    a. A "First Order" badge after a user's first order is marked `DELIVERED`.
    b. A "Top Reviewer" badge after a user submits their 5th review.
6.  If a user has not earned any badges, the "Achievements" tab displays a friendly message encouraging them to engage with the platform.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Create a new interface: `export interface Badge { id: string; name: string; description: string; icon: React.FC<{className?: string}>; }`.
    -   Update the `User` interface to include an optional array: `earnedBadgeIds?: string[];`.

-   **Constants (`constants.tsx`):**
    -   Create a new exported constant, `ALL_BADGES: Badge[]`, which will act as the master list of all available badges in the system.
    -   This list will include initial badges like "First Order," "Five Orders," "First Review," and "Top Reviewer," each with a unique ID and description.
    -   Create new SVG icon components to visually represent each new badge (e.g., `FirstOrderBadgeIcon`, `TopReviewerBadgeIcon`).

-   **API Layer (`api/mock.ts`):**
    -   The mock handler for `PUT /api/orders/:id/status` will be updated. When an order's status is set to `DELIVERED`, it will check if it's the user's first delivered order. If so, it will find the user in `db.users` and add the "First Order" badge ID to their `earnedBadgeIds` array.
    -   The mock handler for `POST /api/providers/:id/reviews` will be updated. After adding a review, it will check the total number of reviews submitted by that user. If the count reaches 5, it will add the "Top Reviewer" badge ID to their `earnedBadgeIds` array.

-   **Component Creation (`components/AchievementsPanel.tsx`):**
    -   A new component will be created to render the user's earned badges.
    -   It will receive the user's `earnedBadgeIds` as a prop.
    -   It will filter the global `ALL_BADGES` constant to find the specific badges the user has earned.
    -   It will render a grid of these badges, each displaying its icon, name, and description.

-   **Component Integration (`components/ProfilePage.tsx`):**
    -   Add a new "Achievements" tab to the main navigation on the profile page.
    -   Render the new `AchievementsPanel` when this tab is active, passing the `fullUser.earnedBadgeIds`.
