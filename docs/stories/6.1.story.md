# Story 6.1: AI-Powered Demand Forecasting

-   **Epic:** 6 (AI-Powered Business Intelligence Suite for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, I want to use an AI tool that predicts which of my menu items will be popular in the near future, so that I can better plan my inventory and promotions.

---

### Acceptance Criteria:

1.  **Given** a Provider is on the `AnalyticsPage`,
    **Then** a new panel titled "AI Demand Forecast" must be visible.

2.  **Given** the provider has fewer than a minimum number of past orders (e.g., 5),
    **When** they view the forecast panel,
    **Then** the "Forecast" button must be disabled with a message explaining more data is needed.

3.  **Given** a provider has sufficient order data,
    **When** they click the "Forecast Next Week's Demand" button,
    **Then** a loading indicator must be displayed while the AI processes the data.

4.  **Given** the AI analysis is complete,
    **When** the forecast is displayed,
    **Then** it must show a list of predicted popular menu items.

5.  **Given** a predicted item is displayed,
    **When** the user views it,
    **Then** a short, AI-generated reason for the prediction must also be visible (e.g., "Trending based on recent orders").

---

### Technical Specification:

-   **Component Creation (`components/DemandForecastPanel.tsx`):**
    -   Create a new, self-contained component `DemandForecastPanel` that accepts `orders: Order[]` and `menu: Meal[]` as props.
    -   This component will manage its own internal state for `isLoading`, `error`, and the `forecast` result.
    -   It will contain the button to trigger the forecast and the UI to display the results.

-   **AI Service (`services/geminiService.ts`):**
    -   Create a new function `forecastDemand(orders: Order[], menu: Meal[], token: string): Promise<DemandForecastResult>`.
    -   This function will call a new backend endpoint: `POST /api/ai/demand-forecast`.

-   **Mock API (`api/mock.ts`):**
    -   Implement a mock handler for `POST /api/ai/demand-forecast`.
    -   This handler should receive the orders and menu, and return a plausible, hardcoded `DemandForecastResult` object for testing. The result should include a few items from the provided menu.

-   **Type Definition (`types.ts`):**
    -   Add new interfaces to support the feature:
        ```typescript
        export interface ForecastedItem {
            itemName: string;
            reason: string;
        }

        export interface DemandForecastResult {
            predictedItems: ForecastedItem[];
            forecastPeriod: string;
        }
        ```

-   **Component Integration (`components/AnalyticsPage.tsx`):**
    -   Import and render the new `DemandForecastPanel` component.
    -   Pass the fetched `orders` and `provider.menu` to it as props.
    -   Place it logically within the page layout, for example, after the "AI Business Summary" panel.

-   **Constants (`constants.tsx`):**
    -   Add a new `TrendingUpIcon` for use in the `DemandForecastPanel` header to give it a distinct visual identity.
