# Story 20.2: Customer Plan Discovery & Purchase

-   **Epic:** 20 (Tiffin Service Subscription Engine)
-   **Status:** Done

---

### User Story:
As a Customer, I want to see and purchase tiffin plans directly from a provider's page and add them to my cart like a regular item.

---

### Acceptance Criteria:

1.  **Given** a Customer is on a `MealProviderDetails` page for a provider who offers tiffin plans.
2.  **When** they view the page, **Then** a new "Tiffin Plans" section must be visible.
3.  **Given** a plan is displayed, **Then** it must show the plan's name, price, duration, and description.
4.  **Given** a plan is displayed, **Then** it must have a "View Sample Menu" button which opens a modal showing the tentative weekly menu in a clear table format.
5.  **Given** a plan is displayed, **Then** it must have an "Add to Cart" button.
6.  **Given** the Customer adds a plan to their cart, **Then** it must appear as a unique item in the `CartModal`.
7.  **Given** a plan is in the cart, **Then** it should not have a quantity selector (quantity is always 1). If the user tries to add the same plan again, it should not be added.
8.  **Given** the cart contains a plan, **Then** the total price must be calculated correctly.

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   The `CartItem` interface has been refactored to support both meals and plans. It no longer inherits from `Meal` and now includes an `itemType: 'MEAL' | 'PLAN'` discriminator property. Optional fields have been added to support both types within a single interface.

-   **State Management (`providers/CartProvider.tsx`):**
    -   The `addToCart` function has been updated to accept either a `Meal` or a `TiffinPlan` object. It uses a type guard (`'duration' in item`) to determine the `itemType`.
    -   For `PLAN` types, `addToCart` now checks if the plan is already in the cart and prevents duplicates.
    -   The `updateQuantity` function has been updated to prevent quantity changes for `PLAN` type items.

-   **Component Creation (`components/SampleMenuModal.tsx`):**
    -   A new modal component has been created to display the `sampleMenu` in a user-friendly table format.

-   **Component Refactoring:**
    -   **`components/MealProviderDetails.tsx`**: A new "Tiffin Plans" section has been added. It conditionally renders if the provider has plans, mapping over them to create display cards. It manages the state for opening the `SampleMenuModal`. The "Add to Cart" button on each card calls the updated `addToCart` function.
    -   **`components/CartModal.tsx`**: The `CartLineItem` sub-component has been updated to conditionally render items based on their `itemType`. Plan items are displayed without a quantity selector and use a different icon.
