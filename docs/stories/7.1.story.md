# Story 7.1: Provider-Initiated Review Reminders

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done

---

### User Story:
As a Provider viewing a specific customer's profile, I want to see which of their past orders have not been reviewed and be able to send them a friendly (simulated) reminder, so that I can proactively encourage more feedback for my kitchen.

---

### Acceptance Criteria:

1.  **Given** a Provider is on the `CustomerProfilePage` for a specific customer,
    **When** they view the list of that customer's past orders,
    **Then** any order that has not yet been reviewed (`reviewSubmitted: false`) must display a "Send Review Reminder" button.

2.  **Given** an order has already been reviewed (`reviewSubmitted: true`),
    **When** the Provider views that order card,
    **Then** the "Send Review Reminder" button must not be visible.

3.  **Given** a Provider clicks the "Send Review Reminder" button for an order,
    **When** the action is performed,
    **Then** the button must immediately be replaced by a "Reminder Sent" status message and become non-interactive for the remainder of the session.

4.  **Given** the "Send Review Reminder" action,
    **When** it is triggered,
    **Then** it should not require a backend API call; a local UI state change is sufficient for this simulation.

---

### Technical Specification:

-   **Component (`components/CustomerProfilePage.tsx`):**
    -   Introduce a new `useState` hook to manage a `Set` of `orderId` strings for which a reminder has been sent in the current session. Example: `const [remindersSent, setRemindersSent] = useState(new Set<string>());`
    -   Create a handler function `handleSendReminder(orderId: string)` that adds the given `orderId` to the `remindersSent` set.
    -   Inside the `customerOrders.map(...)` loop, for each order card, add a new section at the bottom.
    -   This section will use conditional rendering:
        -   If `order.reviewSubmitted` is `true`, render nothing.
        -   If `order.reviewSubmitted` is `false`:
            -   Check if `remindersSent.has(order.id)`.
            -   If `true`, display a static "Reminder Sent" text with a checkmark icon.
            -   If `false`, display the "Send Review Reminder" button, which calls `handleSendReminder(order.id)` on click.

-   **Constants (`constants.tsx`):**
    -   Add a new `BellIcon` SVG component to be used in the "Send Review Reminder" button for better visual communication.
