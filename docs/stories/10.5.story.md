# Story 10.5: Implement Theme-Aware Footer

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done

---

### User Story:
As a user, I want the application's footer to visually match the currently active theme, so that the entire application has a cohesive and immersive look and feel.

---

### Acceptance Criteria:

1.  **Given** a user is viewing any page with a footer.
2.  **When** a specific theme (e.g., "Christmas," "Diwali," "Ocean Blue") is active, **Then** the footer's background color must change to a color that complements the active theme (e.g., the theme's "light" color).
3.  **Given** a theme is active, **Then** the text and link colors within the footer must also adapt to use the theme's defined text colors, ensuring readability and aesthetic consistency.
4.  **Given** the theme is changed by the Super Admin, **Then** the footer's appearance must update instantly without requiring a page reload.

---

### Technical Specification:

-   **Component (`components/Footer.tsx`):**
    -   The component's main `<footer>` element will be updated to use CSS variables from the theme system for its `background-color` instead of a static color. Specifically, it will change from `bg-gray-100` to a class that uses a theme variable like `bg-brand-light/60` to apply a subtle, theme-appropriate tint.
    -   Text elements (headings, paragraphs, links) within the footer will also be updated to use theme variables like `text-brand-dark` and `text-text` instead of hardcoded gray values (e.g., `text-gray-800`).

-   **No Other Changes:**
    -   This is a UI-only enhancement. No changes are required in the theming system (`themes.ts`), API, or data models, as it leverages the existing theme infrastructure.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The `Footer.tsx` component now uses theme variables for its styling.
-   [x] The footer's appearance correctly updates when the application theme is changed.
-   [x] The footer remains readable and aesthetically pleasing across all available themes.
-   [x] The application remains fully functional.
