
# Story 19.1: Provider 360-Degree Customer View

-   **Epic:** 19 (The Unified CRM Hub)
-   **Status:** Done

---

### User Story:
As a Provider, when I click on a customer in my CRM, I want to see a unified view that consolidates their entire history with my kitchen—including all past orders, reviews they've left, and our direct message history—so I can have a complete understanding of our relationship in one place.

---

### Acceptance Criteria:

1.  **Given** a Provider navigates to the `CustomerProfilePage` for a specific customer.
2.  **When** the page loads, **Then** it must be visually enhanced into a "360-Degree View".
3.  **Given** the 360-Degree View is displayed, **Then** it must contain a section showing key customer stats (e.g., "Total Orders," "Total Spend," "Reviews Submitted").
4.  **Given** the 360-Degree View is displayed, **Then** it must contain a tabbed interface to organize the customer's history.
5.  **Given** the tabbed interface is visible, **Then** it must include tabs for "Order History," "Message History," and "Reviews".
6.  **Given** the "Message History" tab is selected, **Then** it must display a list of all conversation threads from both direct inquiries and order-related messages for that customer.
7.  **Given** the user clicks on a message thread, **Then** the `ConversationModal` must open, displaying the full conversation history for that thread.

---

### Technical Specification:

-   **Component (`CustomerProfilePage.tsx`):**
    -   The component's data fetching logic in `useEffect` will be enhanced to fetch all of the provider's pre-order inquiries using `inquiryApi.getInquiriesForProvider` in addition to the existing order and provider data.
    -   A `useMemo` hook will be implemented to calculate key customer stats (total orders, total spend) by filtering the fetched orders for the current customer.
    -   Another `useMemo` hook will be implemented to consolidate all message threads. It will filter `customerOrders` for those with messages and filter `inquiries` for those matching the `customerId`. The combined list will be sorted by the most recent message.
    -   The component's UI will be restructured to include the new "Key Stats" section and a tabbed interface for "Order History," "Message History," and "Reviews".
    -   The "Message History" tab will render a list of conversation summaries. Clicking on a summary will set the state to open the `ConversationModal` with the data for that specific thread.

-   **No New Components:** This story can be implemented by refactoring the `CustomerProfilePage.tsx` and reusing the existing `ConversationModal.tsx`.
