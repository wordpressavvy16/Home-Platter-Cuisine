# Story 10.4: Add Hanging Lamp Decorations to Festive Themes

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done

---

### User Story:
As a user, during festive periods like Diwali, Navratri, and Ganesh Chaturthi, I want to see a beautiful hanging lamp decoration on the screen to enhance the festive atmosphere.

---

### Acceptance Criteria:

1.  **Given** the "Diwali", "Navratri", or "Ganesh Chaturthi" theme is active.
2.  **When** a user views any page, **Then** a decorative hanging golden lamp must be visible in the top-right corner of the screen.
3.  **Given** the hanging lamp is visible, **Then** it must have a subtle, gentle swaying animation.
4.  **Given** any other theme (e.g., "Default Orange", "Christmas") is active, **Then** the hanging lamp decoration must not be visible.
5.  **Given** the "Diwali" theme is active, **Then** the new hanging lamp must be displayed in *addition* to the existing floating diya background effect, not replacing it.

---

### Technical Specification:

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface has been extended to include a new optional property in its `decorations` object: `sideDecoration?: 'hanging-lamp';`.
    -   The theme objects for "Diwali", "Navratri", and "Ganesh Chaturthi" have been updated to include `sideDecoration: 'hanging-lamp'`.

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   The component has been refactored to handle both `backgroundEffect` and the new `sideDecoration` simultaneously.
    -   It now renders a single container `div` and conditionally populates it with particle animations (from `backgroundEffect`) and/or a static decorative element (from `sideDecoration`).
    -   When `sideDecoration` is 'hanging-lamp', it renders the new `HangingLampIcon` positioned absolutely in the top-right.

-   **Constants (`constants.tsx`):**
    -   A new SVG icon, `HangingLampIcon`, has been created to represent the decorative golden lamp.

-   **Animation (`index.html`):**
    -   A new CSS keyframe animation named `gentle-sway` has been added to provide a subtle back-and-forth rotation effect for the lamp.
