# Story 2.11: Provider Photo Gallery

-   **Epic:** 2 (Provider Storefront & Product Management)
-   **Status:** Done

---

### User Story:
As a Provider, I want to upload and manage a gallery of photos for my kitchen storefront, so that I can visually showcase my food, my kitchen's hygiene, and my brand's personality to attract more customers. As a Customer, I want to view this gallery to build trust and get a better sense of the food before I order.

---

### Acceptance Criteria:

1.  **Given** a Provider is on the `EditProfilePage`,
    **When** they view the page,
    **Then** a new "Photo Gallery" management section must be visible.

2.  **Given** the Provider is managing their gallery,
    **When** they provide an image URL and click "Add Photo",
    **Then** the new photo must be added to their profile and displayed in a list of manageable thumbnails.

3.  **Given** the Provider is viewing their list of gallery photos,
    **When** they click a "Delete" button on a photo,
    **Then** the photo must be removed from their gallery.

4.  **Given** a Customer is on a `MealProviderDetails` page,
    **When** the provider has gallery photos,
    **Then** a new "Photo Gallery" section must be visible, displaying the images in a visually appealing format (e.g., a grid or carousel).

---

### Technical Specification:

-   **Data Model (`types.ts`):**
    -   Update the `MealProvider` interface to include an optional array of strings: `galleryImages?: string[];`.

-   **API Layer (`api/mock.ts`):**
    -   The existing `PUT /api/providers/:id` mock endpoint will be used. Its object-spreading logic will correctly handle the addition or update of the `galleryImages` array when the provider's profile is saved.

-   **Provider UI (`components/EditProfilePage.tsx`):**
    -   A new state will be added to manage the list of gallery image URLs.
    -   A new UI section will be created with a text input for image URLs and an "Add" button.
    -   A grid will be rendered to display the current gallery images, each with a "Delete" button.
    -   The main `handleSubmit` function will be updated to include the `galleryImages` array in the payload sent to the `updateProviderProfile` API.

-   **Customer UI (`components/MealProviderDetails.tsx`):**
    -   A new "Photo Gallery" section will be added.
    -   This section will be conditionally rendered only if `provider.galleryImages` exists and is not empty.
    -   It will map over the `galleryImages` array and display the photos in a responsive grid.
