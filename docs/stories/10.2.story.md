# Story 10.2: Super Admin Festive Theming Engine

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done

---

### User Story:
As a Super Admin, I want to activate and deactivate platform-wide "festive themes" (e.g., Christmas, Diwali) that go beyond simple color changes to add decorative, event-specific elements to the UI, so that I can create a more engaging and timely experience for all users.

---

### Acceptance Criteria:

1.  **Given** a Super Admin is on the `SuperAdminDashboard`.
2.  **When** they view the "Dynamic Platform Theming" panel, **Then** new themes like "Christmas" and "Diwali" must be available for selection.
3.  **Given** the Super Admin selects the "Christmas" theme, **Then** the application's color scheme must change, and a subtle, animated snowfall effect must appear in the background of all pages.
4.  **Given** the "Christmas" theme is active, **Then** a small, decorative snowflake icon must appear in the main `Header` next to the logo.
5.  **Given** the Super Admin selects the "Diwali" theme, **Then** the color scheme must change, and a subtle, floating diya lamp animation must appear in the background.
6.  **Given** the "Diwali" theme is active, **Then** a small, decorative diya icon must appear in the main `Header`.

---

### Technical Specification:

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface has been extended to include an optional `decorations` object, which can define properties like `backgroundEffect` and `headerIcon`.
    -   New theme objects for "Christmas" and "Diwali" have been created, utilizing these new properties to specify their unique decorative elements.

-   **Component Creation (`components/BackgroundDecorator.tsx`):**
    -   A new, self-contained component has been created to render the background animations.
    -   It uses the `useTheme` hook to read the active theme's `backgroundEffect`.
    -   It renders a lightweight, performant CSS animation (defined in `index.html`) based on the active effect.
    -   This component has been added to the root `App.tsx` layout to apply the effect globally.

-   **Component (`components/Header.tsx`):**
    -   The `Header` component now uses the `useTheme` hook to check for a `headerIcon` in the active theme's decorations.
    -   It conditionally renders the appropriate icon (e.g., `<SnowflakeIcon />`) next to the site logo when a festive theme is active.

-   **Constants (`constants.tsx`):**
    -   New SVG icons (`SnowflakeIcon`, `DiyaIcon`) have been added to support the conditional header decorations.

-   **Component (`SuperAdminDashboard.tsx`):**
    -   The `ThemeCard` has been updated to display a visual indicator for themes that include special `decorations`.
