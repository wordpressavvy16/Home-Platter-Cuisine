# Story 7.5: Provider-Managed Coupon Codes

-   **Epic:** 7 (Advanced CRM & Marketing Automation for Providers)
-   **Status:** Done

---

### User Story:
As a Provider, I want to create and manage unique coupon codes (e.g., "WELCOME15") that offer a percentage discount, so that I can run targeted marketing campaigns and incentivize new or repeat customers.

---

### Acceptance Criteria:

1.  **Given** a Provider is on their `DashboardPage`,
    **When** they view the page,
    **Then** a new panel for "Manage Coupons" must be visible.

2.  **Given** a Provider clicks "Create Coupon",
    **When** the action is performed,
    **Then** a modal must appear with a form to create a new coupon (Code Name, Discount Percentage, Expiration Date).

3.  **Given** a Provider views the "Manage Coupons" panel,
    **When** they have created coupons,
    **Then** a list of their active and expired coupons must be visible.

4.  **Given** a Customer is on the `CheckoutPage`,
    **When** they are reviewing their order summary for a specific provider,
    **Then** an input field to "Add Coupon Code" must be visible.

5.  **Given** a Customer enters a valid, active coupon code for that provider,
    **When** they apply it,
    **Then** the order subtotal for that provider must be discounted, and the discount amount should be clearly displayed in the summary.

6.  **Given** a Customer enters an invalid or expired code,
    **When** they try to apply it,
    **Then** a clear error message must be shown.

---

### Technical Specification:

-   **Component Creation (`components/CouponManager.tsx`, `components/CouponFormModal.tsx`):**
    -   `CouponManager.tsx`: A new component for the `DashboardPage` to list a provider's coupons and contain the "Create New" button.
    -   `CouponFormModal.tsx`: A modal containing the form for creating a new coupon code.

-   **API Service:**
    -   **`api/providerApi.ts`**: `createCoupon(providerId, couponData, token)` and `getCoupons(providerId, token)` have been added.
    -   **`api/orderApi.ts`**: `validateCoupon(providerId, code, token)` has been added.

-   **Mock API (`api/mock.ts`):**
    -   Handlers for the new provider API endpoints (`POST /api/providers/:id/coupons`, `GET /api/providers/:id/coupons`) have been implemented.
    -   A handler for `POST /api/orders/validate-coupon` has been implemented to check if a coupon is valid.
    -   The `MealProvider` object in the mock DB has been updated to include a `coupons: Coupon[]` field.

-   **Type Definition (`types.ts`):**
    -   A new `Coupon` interface has been added.
    -   The `MealProvider` interface has been updated to include `coupons?: Coupon[];`.

-   **Component Integration:**
    -   **`DashboardPage.tsx`**: The new `CouponManager` has been added as a draggable panel.
    -   **`CheckoutPage.tsx`**: The component has been updated with state and logic to handle coupon code input, validation, and application of discounts to the order total.
