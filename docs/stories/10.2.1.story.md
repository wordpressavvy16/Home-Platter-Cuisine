# Story 10.2.1: Enhance Ganesh Chaturthi Theme Animation (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.2

---

### User Story:
As a user, when the Ganesh Chaturthi theme is active, I want to see a background animation of falling Modaks along with the existing hibiscus flowers, to create a more authentic and visually rich festive experience.

---

### Acceptance Criteria:

1.  **Given** the "Ganesh Chaturthi" festive theme is activated by the Super Admin.
2.  **When** a user views any page of the application, **Then** a background animation of gently falling particles must be visible.
3.  **Given** the animation is active, **Then** the falling particles must be a mix of both hibiscus flowers (`🌺`) and Modak icons.
4.  **Given** the animation is active, **Then** it must remain subtle, aesthetically pleasing, and not interfere with the main content's readability.
5.  **Given** the `hibiscus-fall` effect existed previously, **Then** it should be replaced by this new, more detailed animation for this specific theme.

---

### Technical Specification:

-   **Component (`components/BackgroundDecorator.tsx`):**
    -   A new `backgroundEffect` case, `'ganesh-chaturthi-fall'`, has been added.
    -   This new logic renders a mix of particles: `ModakIcon` components and hibiscus flower emojis (`🌺`).
    -   The logic is modeled after the `dandiya-fall` effect to ensure a similar density and aesthetic.

-   **Theming System (`themes.ts`):**
    -   The `Theme` interface's `backgroundEffect` type has been updated to include the new `'ganesh-chaturthi-fall'` option.
    -   The 'Ganesh Chaturthi' theme object's `backgroundEffect` property has been changed from `'hibiscus-fall'` to the new `'ganesh-chaturthi-fall'`.
