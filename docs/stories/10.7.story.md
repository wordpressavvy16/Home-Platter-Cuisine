# Story 10.6.1: Refine Eid Theme Visuals (Iteration)

-   **Epic:** 10 (Theming & Personalization)
-   **Status:** Done
-   **Iterates on:** Story 10.6

---

### User Story:
As a user, when the Eid theme is active, I want the crescent moon and star icon used in the header and background animation to be a more delicate, narrow crescent with a separate star above it, to better reflect a traditional and aesthetically pleasing design.

---

### Acceptance Criteria:

1.  **Given** the "Eid" festive theme is active.
2.  **When** a user views the application `Header`, **Then** the festive icon must be a thin crescent moon with a star positioned above it, opening towards the top-right.
3.  **Given** the "Eid" theme is active, **When** a user views the background animation, **Then** the falling particles must use the same refined crescent moon and star icon.
4.  **Given** the icon is updated, **Then** it must maintain a clean and modern aesthetic consistent with the application's design language.

---

### Technical Specification:

-   **Component (`constants.tsx`):**
    -   The SVG path data within the `CrescentMoonAndStarIcon` component will be replaced with a new design.
    -   The new design will consist of two `<path>` elements: one for a narrow crescent moon and one for a small star, positioned to appear as a single unit.
    -   No other components need to be modified, as both `Header.tsx` and `BackgroundDecorator.tsx` reference this single icon component, ensuring the change is applied globally.

---

### Definition of Done (DoD):
-   [x] Code implemented as per the technical specification.
-   [x] The SVG for `CrescentMoonAndStarIcon` has been updated to the new, refined design.
-   [x] The updated icon is correctly displayed in both the header and the background animation for the Eid theme.
-   [x] The application remains fully functional.
-   [x] Story status updated to 'Done' in `changelog.md`.
