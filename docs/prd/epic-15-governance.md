### Epic 15: Platform Governance & Trust Tools

This epic focuses on building a suite of tools for the Super Admin to maintain the integrity, safety, and fairness of the marketplace. These features are critical for long-term platform health and user trust.

-   **Story 15.4 (Super Admin Customer Compensation Tools):** A feature for the Super Admin to issue a platform-funded, single-use coupon to a customer as part of a dispute resolution, ensuring customer satisfaction. (Completed)
-   **Story 15.3 (Super Admin Order Dispute Resolution System):** A feature for customers to formally report issues with delivered orders and for a Super Admin to view, manage, and resolve these disputes from a dedicated dashboard panel. (Completed)
-   **Story 15.2 (Provider Quality Monitoring System):** A feature for the Super Admin to see a list of automatically-flagged providers who fall below key quality thresholds (e.g., low average rating, high order cancellation rate) for proactive intervention. (Completed)
-   **Story 15.1 (Super Admin Review Moderation System):** A feature for users to flag inappropriate reviews and for the Super Admin to review and act on these flags by either dismissing them or deleting the offending review. (Completed)
